# 影境装扮：语义、纹理与播放图标

按用户纠正，操作图标采用实际游戏道具，并让状态对应到素材：

|动作|默认／未激活|激活及成功反馈|
|---|---|---|
|点赞|异铜锭|万锻天外异铜，原位铜色光效及低音量升级音效|
|投币|用户提供的玉佩原图|原位翠色光效，1／2 枚选项仍保留，双币以两枚错位区分|
|收藏|用户提供的记忆之花原图|原位蓝色光效，收藏／长按选夹行为保留|
|播放|用户官网包 `play.png`|暂停仍显示暂停，不把暂停也替换为播放|

点赞状态接入视频主操作栏、动态卡片、动态详情评论与视频评论，跟随实际 `IsLiked`。只有成功操作触发反馈，取消、失败、过期请求不庆祝。按用户本轮纠正，影境反馈改为现有道具轮廓原位亮起，不再叠画另一份道具或弹出素材；星引擎继续使用原角色动效。

影境共用默认开启的“主题互动效果”开关，在说明中提示低音量音效包。点赞成功播放用户指定的“武器升级-成功”，嵌入振幅降至 18% 的完整 WAV。关闭互动效果一并停用光效和声音，原视频播放器的音量及音轨不受影响。

影境顶部条与侧栏已撤下场景、人物和大标志，按用户最新纠正改用官网包的织物及金箔材质，原宣纸与水墨转移到视频卡片区和视频详情内容背景。暗色织物单独调节透明度，保留可见的细纹。横向、纵向分隔均采用愿望单原始细刀痕图，取代实色线。个人卡片及开屏仍使用完整内容图（开屏画面已于 0.2.6 移除，个人卡片不受影响）。

播放原图统一接入共享图标组件，覆盖首页等视频卡片、动态视频卡片、普通播放器、小窗控件、独立直播间。影境控制按钮内的播放圆环按按钮实际大小适配，按可见轮廓留少量边距，普通 40px 按钮使用约 38px 图标；暂停态和卡片播放量小图标保留原尺寸。播放／暂停数据绑定保留；切换装扮时已打开的控件会立即刷新。

材料导航入口来自用户指定的 [提纯靛晶](https://wiki.biligame.com/yingzhiren/提纯靛晶) 页面，106 个导航条目索引、10 种候选原图、来源页及哈希位于工作区 `theme-research/phantom-blade-zero/materials/`。最终点赞素材按用户指定采用异铜锭和万锻天外异铜；长明灯火等其余素材仅保留作研究候选。

用户图片及播放图标逐字节保存在 `interaction-originals/` 并复制入应用；显示阶段按透明边界适配，不改写原像素。图片与材料来源详见应用 `Assets/Skins/PhantomBladeZero/SOURCES.md`。

验证包含真实视频／动态卡片、普通与小窗同步、直播播放／暂停、已有页面切换装扮、点赞双状态和投币数量区分；界面截图保存在 `artifacts/touch-tests/phantom-*.png`。测试使用隔离账号夹具，没有对真实账号点赞、投币或收藏。

# BiliTouch 0.3.9

本版专项解决**高密弹幕场景下的严重掉帧与微卡顿问题**，对点播与直播弹幕的字形渲染、GPU 纹理缓存、控件对象池、泳道防追尾与逐帧平滑派发进行全链路重构，继续同步提供 **Windows x64** 与 **Windows ARM64** 原生双架构安装器。

### 高密弹幕渲染与调度性能优化
- **描边弹幕告别矢量路径三角化与高分屏双倍构建**：重写 `OutlinedDanmakuText`，移除对每个汉字提取贝塞尔轮廓的 `FormattedText.BuildGeometry()` 与绕过硬件字形缓存的 `DrawGeometry` 圆角描边细分，改为基于 DirectWrite 硬件字形图集（Glyph Atlas）的四向描边 + 中心填充；构造时直接对齐主窗口真实 DPI（消除 125%～225% 缩放屏下先按 1.0 构建再在 `MeasureOverride` 重建的双倍开销），并缓存 `Typeface` 与支持 `SetContent` 原地复用。
- **共享 `BitmapCache` GPU 纹理平移**：硬件加速开启时为所有在飞弹幕容器挂载共享冻结 `BitmapCache`，每条弹幕上屏时仅栅格化一次为 GPU 纹理，横穿屏幕的数百帧内仅在合成器中平移单个纹理矩形，彻底消除每帧对数十条文本重复做亚像素字形过滤与重绘。
- **弹幕视觉树与槽位对象池（稳态零分配）**：`PlayerWindow` 新增 `_danmakuBorderPool` / `_flyingPool` 对象池，`LiveOverlayRenderer` 新增 `_plainPool` / `_outlinedPool` 与颜色笔刷缓存；弹幕飞出画面或清屏时自动回收复用 `Border`、`TextBlock`、`OutlinedDanmakuText` 与 `TranslateTransform`，消除高频建树与 GC 抖动，同时移除直播弹幕未开描边时的逐元素 `DropShadowEffect` 离屏高斯模糊。
- **零分配字宽预估、防追尾泳道校验与逐帧平滑派发**：新增零分配算术字宽估算 `EstimateDanmakuWidth`，在触碰 UI 控件前先行完成右侧入场间距与**长短弹幕速度差防追尾校验**，并移除 UI 线程同步 `border.Measure`；在 `OnDanmakuRendering` 渲染帧内按时间戳平滑补发到期弹幕（消解 4Hz `TimeChanged` 250ms 攒批建树峰值），泳道占满时立即短路跳过同时间戳冗余弹幕（60,000 条密集突发派发仅需 ~1.2ms）。

# BiliTouch 0.3.11

面向 Windows 平板与桌面端，根治**跳转进度后音频连续断音/异响**、显著改善**跳转与倍速切出音频丢失**，补全**原生字幕功能**并升级**键盘右方向键长按倍速**，同步提供原生 **x64** 与 **ARM64** 双架构安装包。

## 核心修复与新功能

### 1. 根治跳转进度概率触发的音频连续断音与异响（`VlcCore`）
- **实测根因**：在真实 1080P60 DASH 双流（`vmem + WASAPI` 44.1 → 48 kHz）下，`v0.3.7` 强制开启的 `--audio-resampler=speex_resampler --speex-resampler-quality=10` 在跳转后出现 >60ms 音频漂移并触发 `up-sampling` 动态微调采样率时，重建高阶 sinc 滤波表会将音频线程阻塞约 `295ms`（实测即使降到 quality=4 仍会偶发 ~90ms 阻塞），随即落入 `playback too late: flushing buffers → [wasapi] reset → up-sampling` 的无限死循环，表现为持续约每 0.3 秒断音/异响且无法自愈。
- **修复**：`VlcCore` 不再覆盖 `--audio-resampler`，恢复 LibVLC 3.0.24 原生默认重采样管线。同组 10 次随机跳转 + 3 轮倍速实测中，连续 flush 死循环从 **64 次 / 698 丢包**降至 **0 次 / 0 丢包**。

### 2. 修复跳转进度、倍速与退出倍速时的音频丢失（`SeekWatchdog` / `BufferPolicy`）
- **消除跳转后首段 200~500ms 人为静音**：LibVLC 3.0.24 的 WASAPI 在 seek 预滚阶段自身已完成静音与同步起播，移除常规 seek 时的 `MuteForSeek()` 强压音量为 0 的旧逻辑（不再等待看门狗两跳心跳与异步音量补写才恢复），改为到位后校验 `EnsureAudioVolumeSynced()` 兜底对齐。
- **缩短倍速/退倍速静音空洞并强化音轨自愈**：`BufferPolicy` 将 DASH 估算码率回调至 `2.5 Mbps`（保留 `1000ms` 最低下限与卡顿自动 `+1000ms` 策略），避免正常宽带被误推到 `2000~3000ms` 导致 LibVLC 3 `2x → 1x` 时钟换算静音被放大到 `1.06~1.55s`（实测减半至 `~0.55s`）；同时为菜单倍速切换与长按倍速松手统一补齐音量对齐与延迟音轨自愈检查。

### 3. 补全完整原生字幕功能（B 站 CC / AI 字幕 + 本地外挂/内嵌字幕）
- **在线字幕接入**：新增 `ApiClient.Subtitles` 接入 `/x/player/wbi/v2`（含非 WBI 兜底）拉取视频 CC 与 AI 字幕轨道，离线缓存联网状态下同样自动后台补拉字幕。
- **原生渲染与交互**：在播放器画面底部新增原生半透明胶囊字幕层 `SubtitleOverlay`（支持重叠多行拼接、字号按窗口宽度与设置缩放、随控制栏显隐自动抬高/落回避让）；控制栏新增「字幕」按钮与弹层，支持关闭字幕、多轨切换、字号百分比滑杆（75%~200%，持久化）以及 `C` 键快捷开关。
- **本地字幕支持**：支持在弹层手动加载 `.srt / .vtt / .json` 外挂字幕、本地视频自动识别同目录同名 `.srt/.vtt/.json` 字幕，以及识别本地容器内嵌 SPU 字幕轨道。

### 4. 键盘右方向键 `→` 长按倍速
- 对齐 B 站桌面端与网页端操作习惯：**短按 `→` 快进 5 秒**（`Shift+→` 快进 30 秒），**长按 `→` 进入临时倍速快进（2.0x 或更高）**，松开按键或窗口失焦/换片时自动恢复原倍速；主窗、浮层窗口与平板单窗口内嵌模式均完整生效。

# BiliTouch 0.3.6

本版新增面向 Windows 平板竖屏场景的**「平板模式」**与桌面端**「竖屏视频优化」**，并自本版起同步构建与发布 **Windows x64（Intel / AMD）** 与 **Windows ARM64（ARM 版 Surface 等骁龙设备）** 原生双架构安装包。

### 平板模式（面向 Windows 平板竖屏 · 安卓端 B 站布局）
- **形态感知与 Surface 智能提醒**：在「设置 → 通用 → 平板模式」提供「关闭（默认）/ 自动（竖屏或窄窗时启用）/ 始终开启」三档；首次检测到 Microsoft Surface 设备时在顶栏弹出一次性无打扰启用提示；进入 `TabletPortrait` 姿态时主窗口最小宽度自动放宽至 `480 DIP`（含 40px 迟滞防抖），退出时恢复桌面 `840 DIP`。
- **底部四项导航栏与紧凑顶栏**：平板竖屏下左侧 64px 导轨自动收起，切换为底部 56px 四项导航栏（`首页 | 动态 | 我的 | 设置`），消息中心与日夜主题入口移至顶部紧凑操作区；首页网格自适应为 2～3 列大触控间距卡片。
- **单窗口内嵌播放与安卓端详情页布局**：平板竖屏下点播与直播均采用单树双宿主（Single-Tree Dual-Host）原位挂载至主窗口 `EmbeddedPlayerHost`，隐藏底层导航且旋转屏幕不断流；横屏视频顶部 `16:9` 置顶，视频下方直接固定 **`简介 | 评论`** 双标签栏，UP 主信息、标题、播放量、一键三连、分 P / 合集与相关推荐统一收纳在 `简介` 页签内，切换至 `评论` 页签时评论列表紧贴标签栏下方展开。
- **平板竖屏视频高视口与半屏评论抽屉**：在平板竖屏下播放竖屏视频（`9:16` / `3:4`）时，视频舞台默认展开至约 `58%` 窗口高度，向下滚动简介/推荐时平滑收起至紧凑高度；点击 `评论` 标签或评论按钮时，从底部弹出 `65%` 高度的不透明半屏评论抽屉，视频在上方保持连续播放。
- **全站二级页面竖屏适配**：关注动态页左侧 UP 栏转为顶部横向可滑动头像条（`TabletUpStrip`），动态详情页与直播间转为上下单列流式布局；私信页由左右双栏改为「会话列表 ↔ 对话详情」二级全宽下钻（支持返回键与鼠标侧键返回）；个人中心、UP 空间、收藏夹、离线缓存、搜索与设置页全面适配紧凑边距与软键盘聚焦自动滚动。

### 桌面端竖屏视频优化
- **网页布局竖屏视频左置 + 评论区并排右置**：在「设置 → 通用 → 视频详情」新增「竖屏优化」（默认开启）。桌面网页布局检测到竖屏视频（高 > 宽）时，视频舞台自动左置，评论区提至舞台右侧与视频并排同屏浏览，右侧保留 UP 主信息与「简介 / 推荐」侧栏；播放横屏视频或向下滚动触发小窗停靠时保持原有网页布局不变。

### 原生双架构发布（Windows x64 + Windows ARM64）
- **原生 ARM64 支持**：新增 `win-arm64` 构建目标，按运行架构自动加载原生 `libvlc/win-arm64` 与 `WebView2Loader.dll`，消除 ARM 版 Surface 上的 x64 转译开销。
- **双版本同步发布与自动更新兼容**：自 `0.3.6` 起，每次 GitHub Release 同步上传 `BiliTouch-{version}-setup.exe`（x64）与 `BiliTouch-{version}-setup-arm64.exe`（ARM64）两份安装器；内置更新器按当前进程架构自动匹配下载对应架构安装包，同时保持对旧版 x64 客户端自动更新的 100% 向后兼容。

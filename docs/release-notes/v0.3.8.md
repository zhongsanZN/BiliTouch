# BiliTouch 0.3.8

本版修复**评论区动图无法正常显示与播放**以及**退出评论详情后跳回评论区最上层**两项核心评论区体验问题，继续同步提供 **Windows x64** 与 **Windows ARM64** 原生双架构安装器。

### 评论区动图完整支持
- **原生多帧 GIF / 动态 WebP 后台合成解码**：新增 `Helpers/AnimatedImage.cs` 与 `CoverLoader.LoadMediaAsync`，在后台线程完成 GIF89a 逻辑画布合成（支持局部帧偏移、透明通道与全部 4 种 Disposal 方式、标准帧间隔解析及按需降采样与单图内存预算），并兼容多帧动态 WebP，同时维持常规静态 JPEG/PNG 封面的零额外开销快速路径。
- **全场景动图流畅播放与自动停帧**：评论区 GIF 配图缩略图（视频播放页、动态详情页、专栏页）、内联评论图片画廊（`InlineImageGallery`）与独立大图预览窗（`ImagePreviewWindow`）均支持原生逐帧播放；全应用共享单一定时器调度，控件不可见、滑出虚拟化视口、切回简介页或关闭预览时自动暂停与解绑，零后台空转与内存泄漏。
- **动态评论表情（`gif_url`）支持**：`ApiClient.Comments` 解析评论与表情面板时完整保留 `gif_url`（并在 `url` 缺失时自动回退），`CommentText` 内联表情优先按动图播放且在动图不可用时自动回落静态图。

### 评论区退出详情精准还原位置
- **虚拟化列表定位与视口锚点恢复**：在 `VirtualizingCommentPanel` 新增 `ScrollItemIntoView`，先完成恢复可见后的真实高度测量，再按进入详情前记录的原滚动位置与目标评论视口纵坐标精确定位并实例化目标容器，彻底解决引入评论虚拟化后退出具体评论详情总是回到评论区最上层的问题。
- **全布局与边界场景兼容**：完整覆盖并排布局、网页布局、详情页内再次点击楼中楼“回复”不覆盖原锚点，以及在详情页内切换“热门 / 时间”排序导致原评论移位后的自动重定位；同步修复详情页长楼中楼下“查看对话”在虚拟化列表中的定位能力。

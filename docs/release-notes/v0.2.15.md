# BiliTouch 0.2.15

发布日期：2026-11-09。

这一版修复播放器的悬停浮层问题，并优化视频详情页动效、视频帧队列和密集弹幕处理。

## 使用体验修复

- 点播与直播的音量面板，在鼠标从喇叭移向滑杆、快速往返或拖动滑杆到面板外时保持展开，离开后正常收起。关闭面板时的旧延迟任务不会再提前关闭新一轮交互。
- 修复拖动音量后百分比、静音图标未立即更新，以及跳转期间修改音量时界面反馈滞后的问题。
- 打开音量或倍速面板时，点播控制栏保持可用；点击画面收起音量面板时，避免顺带暂停视频。
- 调整弹幕不透明度，已显示的滚动弹幕立即更新，保留当前弹幕，不再为外观调整反复重筛完整时间轴。
- 网页布局大小窗切换修复放大错位、非 16:9 画面与浮层漂移、右栏黑色占位残块、圆角更新和动画收尾问题。

## 流畅度优化

- 大小窗跟手与自动收拢共用合成帧时钟，按实际经过时间推进；反向打断保留当前速度，画面、黑边、弹幕和亮度遮罩一起移动。
- 合成视频上传合并待处理回调并保留新帧；格式切换和关闭时按对应原生回调释放缓冲，补齐 4K 缓冲与像素行对齐保护。
- 弹幕排序、规则编译与重筛移到后台；换片、关闭或再次改规则时，过期结果不会覆盖当前视频。异常回溯的正则一次超时后跳过该规则，保留其他规则。
- 密集弹幕派发加入单次工作预算，无可用泳道时提前拒绝，减少控件创建和布局开销；完整时间轴继续保留以供跳转。
- 减少页头重复绘制，清理隐藏或取消后的动画时钟；关闭播放器时，若仍有其他播放器存活，避免执行大对象堆压缩与工作集回收。

## 使用范围

实时画面连续变形使用「设置 → 通用 → 实验性：WPF 合成视频（vmem）」，重开播放器后生效，默认仍关闭。默认原生播放使用兼容过渡。vmem 的软件解码、像素拷贝与上传成本仍存在，4K、高码率和不同显卡需要结合设备判断。

审查与验证详情见 [代码审查报告](https://github.com/zhongsanZN/BiliTouch/blob/v0.2.15/docs/CODE-REVIEW-AND-MOTION-2026-11-09.md) 和 [0.2.15 验证记录](https://github.com/zhongsanZN/BiliTouch/blob/v0.2.15/docs/RELEASE-0.2.15-2026-11-09.md)。

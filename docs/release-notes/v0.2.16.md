# BiliTouch 0.2.16

发布日期：2026-11-09。

本版补齐网页布局右侧连续让位与「简介 / 推荐」页签，引入金标联盟「一镜到底」连续共享元素过渡与澎湃 OS 4 风格弹簧动效，统一触屏、触控板与鼠标侧滚轮的横向切页体验，并修复滚动弹幕越界与完成播放器模块化重构。

## 网页布局与弹幕边界修复

- **右侧连续让位**：网页布局下视频向右上角小窗过渡及反向收回时，右侧停靠占位高度随同一合成进度（`0 -> 1`）连续插值推进，页签标题行固定在顶部，消除动画结束时内容突然跳变。
- **右侧「简介 / 推荐」双页签**：网页布局将关联推荐视频从简介底部移至右侧独立「推荐」页签，评论区继续留在视频下方；并排（经典）布局保留原有的「简介 / 评论」页签，切换布局或进出全屏时完整保留评论详情与输入草稿。
- **弹幕容器边界裁剪**：为 `DanmakuCanvas`、`VideoAreaRoot` 与 `VideoSurface` 补齐 `ClipToBounds="True"`，根治并排布局与网页布局下滚动弹幕在画面右侧外出生时透出到右侧信息栏的问题。

## 金标联盟「一镜到底」与澎湃 OS 4 动效

- **一镜到底共享元素过渡**：点击视频卡片时捕获封面屏幕几何、圆角与已解码位图（`SeamlessTransitionDirector`），在播放器打开瞬间从原卡片屏幕位置连续展开至播放画布，共享同一份封面图层直至首帧画面就绪，并支持任意时刻零跳变打断与重定向。
- **澎湃 OS 4 物理弹簧参数**：在 `SpringMotion` 中提供二阶解析临界阻尼弹簧配置（`HyperOs4MorphResponse`、`HyperOs4InteractiveResponse`、`HyperOs4SettleResponse`），在 30Hz～240Hz 刷新率下保持帧率无关的位置与速度连续性。

## 触屏、触控板与鼠标侧滚轮横向切页优化

- **全场景跟手中间态**：视频详情页（并排「简介 / 评论」与网页「简介 / 推荐」）、首页信息流（「推荐 / 热门 / 关注」）、我的页及设置/消息页均支持双页并排实时跟手预览。触控板双指横滑在未满整格阈值前即可连续预览相邻页，松手按位移比例平滑落位或回弹。
- **卡片区起手横滑**：修复在首页或我的页的视频卡片上起手横滑时被按钮/卡片拦截导致无法切页的问题，识别为横向滑动后自动取消卡片误触点击并冻结纵向滚动。
- **鼠标侧滚轮方向校准**：在 `FluentWindow` 原生消息层通过 `GetCurrentInputMessageSource` 区分物理鼠标滚轮（`IMDT_MOUSE`）与精确触控板（`IMDT_TOUCHPAD`），自动校准物理鼠标侧滚轮与 `Shift + 滚轮` 的切页方向。

## 架构重构

- 将原超过一万行的 `PlayerWindow.xaml.cs` 按职责拆分为 `PlayerWindow.Danmaku.cs`、`PlayerWindow.Comments.cs`、`PlayerWindow.Episodes.cs`、`PlayerWindow.SponsorBlock.cs` 与 `PlayerWindow.SeamlessMorph.cs` 等分部类，降低单文件维护复杂度。

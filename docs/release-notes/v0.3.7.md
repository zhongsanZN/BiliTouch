# BiliTouch 0.3.7

本版聚焦**音频全链路保真与码率展示**、**反复进退全屏与打开视频偶发冻帧**以及**最大化窗口下切换平板模式半截黑屏**三类高频体验问题修复，继续同步提供 **Windows x64** 与 **Windows ARM64** 原生双架构安装器。

### 音频链路保真、可选杜比与码率展示
- **最高品质音频重采样**：`VlcCore` 在常规模式与 `vmem` 模式下统一启用 `--audio-resampler=speex_resampler --speex-resampler-quality=10`，消除 B 站 44.1 / 96 kHz 音轨经 Windows 48 kHz WASAPI 及 DASH `:input-slave` 漂移补偿在默认低档（3～4/10）下引起的高频发闷与混叠劣化。
- **杜比全景声改为按需可选**：默认自动选轨调整为 **Hi-Res 无损 > 最高立体声 AAC**（同码率按音轨 ID `30280 > 30232 > 30216` 决胜），不再强选 5.1 杜比下混覆盖原生立体声 192k AAC；当视频提供杜比音轨时，可在播放器清晰度菜单的「音质」分区手动点选切换，并在发布包中保留 `libspatialaudio_plugin.dll` 与 `hrtfs/` 支持。
- **非 Hi-Res / 杜比同步展示当前音频码率**：播放器控制栏音质角标与清晰度菜单在普通在线 AAC 播放时直接显示当前码率（如 `192 kbps` / `132 kbps` / `64 kbps`），清晰度切换后同步刷新音轨清单与角标状态。
- **缓存选轨与双流缓冲修正**：修复官方客户端缓存扫描将 `30280`（192k）排在 `30232`/`30216` 之后的排序缺陷；将 DASH 双流自动缓冲估算上调至 6 Mbps 并设 `>=1000ms` 保底，降低高码率 / Hi-Res 播放中的欠载与重采样抖动。

### 播放器稳定性（全屏切换与打开视频防卡死）
- **`D3DImage` 前台缓冲丢失恢复重绑与 GPU 帧同步看门狗**：补齐 `GpuVideoPresenter` 在 `IsFrontBufferAvailable` 失而复得后的 `Image.SetBackBuffer` 重绑及 D3D9Ex 设备状态检查；`VmemVideoView` 新增有界看门狗（GPU Fence 超时或前台缓冲长时间不可用时自动切换兼容合成），输出宽高强制对齐偶数并避开同帧销毁重建共享表面，根治反复进退全屏偶发“画面定格但声音继续”。
- **消除打开视频双加载竞态与遮罩残留**：为 `OnLoaded` 补齐 `_nativeInputVersion == 0` 守卫防止与 `PlayVideo` 并发双加载；补齐 `OnTimeChanged` 安全网对 `"正在缓冲视频…"` 等文案的自动收起；完善 `SeamlessMorph` 复用窗口 `ContentRendered` 钩子与异常中断恢复；`vmem` 模式下跳过 HwndHost 专用黑幕，修复全屏/拖拽遮罩超时死锁并调整退全屏恢复顺序。

### 最大化窗口切换平板模式修复
- **根治最大化切换平板模式半截黑屏**：最大化期间冻结对 `MainWindow` / `LiveRoomWindow` `MinWidth` 的直接修改（由 `WM_GETMINMAXINFO` 动态提供最小跟踪宽度，退出最大化时立即同步）；不再向 WPF 吞掉 `WM_GETMINMAXINFO` 以保持内部最大尺寸缓存实时更新；`DisplaySettingsChanged` 同步刷新最大化边界；解耦 `Responsive` 姿态与宽度动画并在最大化壳层切换后执行内缩对齐与非破坏性帧表面刷新；修复退出平板竖屏态时内嵌播放器偶发钉在旧半屏尺寸的问题。

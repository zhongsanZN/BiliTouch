【推荐更新】本版本彻底解决一镜到底过渡时背景停顿、变糊与错位问题，修复双显卡设备下安装版跨显卡掉帧，新增「界面渲染显卡」与「打开视频详情页时默认最大化」设置项，强烈建议更新。  

✦ 一镜到底零截图真背景与详情页窗口体验  
  • 零截图真背景过渡：彻底摒弃主窗口截图过渡方案，在保留半透明容器壳体随视频封面同步展开与收回的同时，底层直透真实 3K 实时主界面，彻底根治点击瞬间停顿、背景变糊与像素错位。  
  • 详情页默认常规窗口与最大化开关：打开视频详情页不再强制全屏最大化，改为默认以常规窗口尺寸居中展开；同时在「设置 → 通用 → 视频详情」中新增「打开视频详情页时默认最大化」开关供自由选择。  

✦ 界面渲染显卡直连与安装版性能修复  
  • 修复安装版跨显卡掉帧：自动清理旧版本在 Windows 注册表中遗留的强制独显绑定，默认让界面渲染直连显示输出显卡（核显），消除高分屏跨卡回传掉帧与合成回退。  
  • 新增「界面渲染显卡」设置：在「设置 → 通用 / 播放」中支持独立选择界面渲染显卡（自动核显直连 / 指定核显 / 指定独显），并实时显示当前生效的渲染显卡。  
  • 动态 PGO 性能优化：启用 .NET 10 动态分层剖面引导优化（TieredPGO），提升高频列表滚动与手势动画执行效率。  

✦ 澎湃 OS 流体动效与列表交互（自 v0.3.12 累计亮点）  
  • 竖屏优化适配与全场景弹性交互：一镜到底完整适配「竖屏优化」布局；升级导航滑块、卡片按压回弹、弹层生长与评论抽屉动效。  
  • 封面加载防丢图与自愈：修复快速刷视频时部分封面空白的问题，支持损坏缓存自动清理与视口自动补载。  
  • 面板整合与切页零重排：音质移入音量面板、画质增强移入清晰度面板底部；修复设置与消息页切页重排，大图预览支持双指横滑切换。

# BiliTouch 0.2.8

发布日期：2026-11-08。

- 首页回滚时直接复用已缓存封面，减少重复排队与重复解码；已看过的卡片不再重复播放封面淡入。
- 修复网页布局大小窗切换时弹幕在原位置短暂残留，移动开始前隐藏，落位稳定后恢复。
- 修复视频到达右侧小窗后向下跳动：先完成目标占位布局，再确定动画终点。
- 调整截图动画与真实视频的交接顺序：过渡画面上屏后再隐藏原视频，新位置布局完成后再显示视频；撤除整层透明度淡出，减少交接闪烁。

本版包含完整源码标签，只公开 Windows x64 安装器。已完成本地实播及大小窗往返屏幕取样检查；不同显卡、多显示器和极端负载下的表现仍需实机确认，不承诺所有设备绝无闪烁。

10 组回归共 284 项通过；安装器与便携包均完成解包校验和隔离启动播放验证。

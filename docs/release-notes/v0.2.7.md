# BiliTouch 0.2.7

发布日期：2026-11-08。本版包含 0.2.4～0.2.6 的累计改动及最新修订。

- 修复首页加载卡片时的模板异常，保留视口附近卡片虚拟化和统一滚动接管。
- 修复触控板累计距离丢失、末尾输入倍率突变，以及取消后残留滚动命令继续执行的问题。
- 新增 WPF GPU 硬件加速设置，修正配置读取顺序；修改后重启生效。
- 保留影之刃零装扮、原位互动光效与低音量互动音效。
- 关注动态提供综合/视频模式，切换或筛选后补齐首屏。
- 修正内嵌动态详情的主题页头、返回按钮与主题过渡快照清晰度。
- 网页布局评论图片支持原位展开，开屏功能已移除。

完整源码对应本版标签。本版只公开 Windows x64 安装器。

已完成构建，14 组定向回归共 502 项通过；安装器和便携包均完成解包后的隔离播放验证。真实触控板的起停与惯性手感、不同硬件上的持续帧率仍需实机复测，不宣称已经消除全部卡顿。

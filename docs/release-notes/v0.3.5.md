# BiliTouch 0.3.5

本版完成一次全仓深度排错、流畅度优化与宏观架构重构：修复动态点赞图标偶发消失、视频结尾提前截断、直播间静音失效等数十项体验缺陷；新增离线缓存联网加载评论与弹幕；并重构核心模块与工程规范。

### 功能与体验增强
- **离线缓存联网加载评论与弹幕**：播放 BiliTouch 或哔哩哔哩官方客户端的离线缓存视频时，若当前有网则在起播后后台静默加载在线弹幕与评论（支持热门/时间排序、翻页、回复与登录后互动）；无网或网络波动时静默降级、绝不阻塞本地起播或触发失败遮罩，联网后点击评论区「重试」即可补拉。
- **全站状态实时联动（`UserStateBus`）**：引入弱引用全站状态总线，在播放器、直播间、首页卡片、动态页与 UP 主空间任一处点赞、收藏、关注、稍后再看或评转动态后，已缓存的关联页面即时同步或切回自动刷新。
- **全站横滑手感与多屏体验统一**：抽取共享横滑物理内核 `HorizontalSwipePhysics` 与 `IHorizontalSwipeHost`，统一首页、关注页、我的页与顶栏标签的非线性橡胶阻尼和切页动画；`FluentWindow` 初始尺寸改按目标显示器自身 DPI 裁剪，修复多屏异 DPI 下窗口偏大或误裁。

### 关键 Bug 修复
- **动态/专栏点赞图标消失**：`SkinActionIcon` 默认 `Stretch` 改为 `Uniform`、全局三连矢量几何启用 `po:Freeze="True"`、修复动态详情页与专栏页点赞图标在默认主题下画到视口外的问题，并统一与按钮前景色同源绑定消除虚拟化回收脱节。
- **视频结尾提前截断**：针对远端 DASH 音轨提前 `1.5s~10s` EOF 触发 10 秒静默区直接黑屏重播的问题，新增单次尾段纯视频单流收尾补播完整结尾；补齐本地/离线 fMP4 与重播的 `:demux=avformat`；修正 `DashRemuxer` 的 `ctts` 前导零偏移表与多条目 `elst` 主编辑段时长补丁；`vmem` 模式播完自然定格尾帧。
- **播放器与直播间稳定性**：修复直播间音量 > 0 时静音立即被取消、播放器换片后操作按钮忙态锁死、`--mute` 覆写已保存音量、关闭重入双重销毁、合集/分P 切换在 UI 线程同步阻塞 `_mp.Stop()` 及 `GpuVideoPresenter` 异常释放残留等问题。
- **网络、缓存与页面细节**：修复 `-412` 冷静期满桶踩踏、WebView2 清理脚本 CSS/JS 语法报错、`CoverLoader` 共享请求被取消毒化、离线下载阻塞 UI 线程、暂停/隐藏时弹幕 60fps 空转、中键滚屏嵌套自取消、非 100% 缩放主题切换动画裁切、稍后再看与 UP 空间分页锁死等问题；统一会话/设置/缓存为 `AtomicFile` 原子写盘。

### 架构与工程整理
- **巨石模块按域解耦**：将 6,434 行 `ApiClient` 拆分为核心传输核（唯一发包口 `SendThrottledAsync`）+ 8 个业务域模块并清理 ~230 行旧动态解析死代码；将 8,376 行 `PlayerWindow` 拆分为 6 个单一职责子系统。
- **现代工程规范与自检体系**：新增 `AGENTS.md` 与 `docs/ARCHITECTURE.md`，归档历史过程文档至 `docs/archive/`；`TouchTests` 新增一键 `--ci` 聚合套件及 `RenderTargetBitmap` 离屏像素、`DataBindingSource` 零绑定错误等运行期健康探针；`发布.ps1` 自动以 `BiliTouch.csproj` `<Version>` 为单一版本源。

安装器包含程序及播放依赖；下载附件仅上传一个 `setup.exe`，源码随 `v0.3.5` 标签提供。

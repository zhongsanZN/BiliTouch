【推荐更新】本版本全面升级澎湃 OS 级流体动效与「一镜到底」体验，修复刷视频时部分封面无法显示及多项播放面板交互问题，建议所有用户升级。  

✦ 澎湃 OS 流体动效与「一镜到底」重制  
  • 零闪烁满帧展开与收回：彻底消除点开视频中途换窗闪烁与高分屏掉帧，新增详情页容器同步展开与收拢轨迹，过渡丝滑明确。  
  • 完整适配「竖屏优化」：开启竖屏优化后，一镜到底直接对准左侧竖屏视频区等比展开与收回，全程无画面拉伸。  
  • 全场景物理弹性交互：全面升级导航栏胶囊滑块、顶栏分段指示器、视频卡片按压回弹、弹层生长与评论抽屉动效。  

✦ 列表封面与页面交互体验优化  
  • 封面加载防丢图与自愈：修复快速滑动列表时部分卡片封面一直不显示的问题，支持损坏缓存自动清理与视口封面自动补载。  
  • 控制栏与面板布局整合：音质角标与音轨选择移入音量面板，「画质增强」开关移入清晰度面板底部，修复字幕面板点击闪关。  
  • 页面切页零重排与多图横滑：修复设置页、消息页左右切页后的滚动跳变与二次重排；大图预览支持触控板与触屏双指横滑切换。  
  • 评论区细节打磨：当评论的楼中楼回复已全部展示时，不再重复显示“共 1 条 / 共 2 条回复”按钮。

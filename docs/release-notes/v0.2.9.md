# BiliTouch 0.2.9

发布日期：2026-11-08。

## 影境主题

- 影之刃零主题使用游戏原版刀锋鼠标，原生窗口和内嵌网页随主题切换，保留文字编辑、窗口缩放及视频隐藏光标的行为。
- 按指定素材更新首页、动态、我的、设置、分区，以及刷新、返回、左右翻页、暂停、画质和弹幕设置图标。音量改为留声机，静音时显示斜线，播放结束显示水墨「完」。
- 视频详情使用完整火焰、铃铛和花朵；动态、评论等小位置使用简易图案。点赞区分未赞／紫火，投币区分未投／一枚／两枚，收藏后显示蓝色。
- 保留未点赞火焰的内部灰度，增强深浅模式的层次，并提亮深色模式外缘，改善边缘难辨的问题。
- 个人主页叠加侠客移至图片区中央并贴底，去掉底部空隙，避免与底图右侧人物重叠。

## 修复：退出播放器全屏后卡死闪退

上一版（0.2.8）以及 0.2.9 的前几个本地构建，在**网页布局 + 画质增强**下退出播放器全屏时会让整个程序闪退。
Windows 事件日志给出的现场是 `libvlccore.dll 3.0.24`、异常代码 `0xC0000094`（整数除零）。

定位过程与结论：

- 崩溃指令在 `vout_display_PlacePicture()` 里，分子与分母同时为 0 —— 传入的 `video_format_t`
  的 `i_visible_width` / `i_visible_height` **都是 0**（寄存器 `Rax = Rcx = 0`，转储可直接读出）。
- 调用方是 d3d11 输出模块的 `D3D11_UpscalerUpdate()`，只有 `processor` / `super` 两种缩放模式会走进去；
  它在 vout 重建的窗口期会拿到一份已被 `video_format_Clean()` 清零的 `pool_fmt`。
- 退出全屏正是 vout 重建最密集的时刻，网页布局的挂载／卸载还会额外搬动原生视频窗口，
  于是这条路径被稳定命中。上游 3.0.x 至今未修（4.0 才有重构），NuGet 上也没有更新的 3.0.x 包。

本版的处理是三层：

1. **兜住**：给 `vout_display_PlacePicture` 的调用入口加了一道除零守卫。参数会让原函数除零时
   直接返回空矩形（与原函数自身"没有可见画面"的语义一致），其余情况原样转发。
   守卫带确定性自证：把崩溃现场那种全 0 参数喂进去，必须被拦下。
2. **少制造**：退出全屏恢复窗口尺寸从"四次属性赋值"改为**一次**原生 `SetWindowPos`，
   把危险窗口从四次缩到一次。
3. **不叠加**：全屏切换期间推迟网页布局的挂载／卸载，等几何稳定后再做。

## 内置检测更新

- 检查更新不再只是弹窗跳浏览器：找到新版后可在程序内**下载安装器 → 校验 SHA-256 → 静默安装并重启**。
- 安装包信息严格按 `BiliTouch-<版本>-setup.exe` 匹配，且版本必须等于 tag 解析出的版本，
  避免把旧包当新版装上去。
- 下载失败、校验失败、网络不通都保留「前往 GitHub 下载」这条退路。

# 独立直播间（0.1.5）

0.1.4 已先封存到父目录 `dist/BiliTouch-0.1.4`，包含此前的主题、播放器与滚动修订。本轮直播重做从独立的 0.1.5 源码开始。

## 界面与入口

`PlayerService.PlayLive` 打开 `LiveRoomWindow`，不再进入点播详情布局。直播与点播切换时关闭上一种播放窗口，保持只有一个播放源发声。新窗口包括主播、标题、分区、开播状态、公告、关注与网页入口；控制栏只有暂停/回到实时、音量、实际清晰度、弹幕开关与设置、聊天面板开关和全屏。

右侧聊天列表按像素滚动并回收容器；向上阅读暂停跟随并显示新消息数量，可一键返回最新。发送使用直播接口，支持 Enter，失败保留草稿，发送中禁止重复提交，旧房间的响应不能清除新房间草稿。未登录提示、禁言限制与服务端错误显示在侧栏。

没有礼物、购买、打赏、排行榜或 PK 控件。

## 实时通路

- 房间信息优先使用签名的 `getInfoByRoom`，失败后通过 `Room/get_info` 和 `Master/info` 获取基础信息并解析短房间号。
- 弹幕配置优先使用签名的 `getDanmuInfo`；后备为公开播放器 `Danmu/getConf`，兼容 `host_list` / `host_server_list`。
- WebSocket 完成 op=8 认证后才报告已连接；认证与接收超时、心跳、断线退避重连、房间切换代次校验分别处理。
- 同时解析明文、zlib、Brotli 和压缩包中的多个完整包；限制包长、解压体积与嵌套深度。认证、下播和 SC 删除不受普通聊天队列溢出影响。
- 普通聊天积压上限 2048 条，每 50ms 最多向集合追加 40 条，界面保留最新 500 条；画面渲染最多 48 条。不会把进场或礼物广播灌入聊天列表。
- 画面弹幕使用实时单调时钟，匀速移动且按泳道释放，避免长短弹幕追尾。显示偏好和关键词规则沿用全局设置；字幕有暗色阴影，提高亮画面可读性。

## SC 与房间状态

醒目留言从初始房间信息和实时 `SUPER_CHAT_MESSAGE` / `SUPER_CHAT_MESSAGE_JPN` 接收，解析 `user_info.uname`、金额及服务端结束时间。侧栏独立置顶并倒计时，重复 ID 不重复插入；到期移除；`SUPER_CHAT_MESSAGE_DELETE` 同时删除置顶、聊天历史及尚未刷入的消息。删除指令先于原消息到达时也不会使其复活。SC 接收与展示不涉及购买。

开播、下播、房间变更、禁言/解除禁言、观看数和中断消息分别更新界面；定时刷新基础房间信息弥补状态广播缺失。下播停止画面，开播重新取流。窗口关闭先停止计时器/弹幕连接/渲染，再后台停止原生播放，回到 UI 线程解绑视频 HWND，最后释放 MediaPlayer。

## 验证与限制

记录位于 `artifacts/live-room-tests.log`、`artifacts/live-room-network*.log` 和 `artifacts/touch-tests/live-room-*.png`。网络探针默认游客；显式传入会话路径时仅在内存中读取现有会话，用于接收测试，不输出或保存 Cookie，不发送真实弹幕，不关注、不购买。

直播定向 42 项、既有主题/播放器/界面/滚动定向 154 项，共 196 项通过；其中设置弹窗验证实际挂入了原生视频浮层，窄布局验证控制栏最右侧仍位于可视范围。

本地夹具覆盖压缩包、认证、用户/颜色/粉丝牌字段、SC 去重/过期/撤回/乱序、积压上限、元数据与弹幕配置后备、清晰度可用性、发送表单与来源、原生静音视频解码、聊天跟随、全局偏好/关键词、发送草稿和开播/下播/全屏/关闭生命周期。

公开房间 7734200 的游客与现有登录态只读探针均已得到 `videoPlaying=true`、`snapshot=true`、`chatAuthenticated=true`、`realtimeMessages=1`，没有错误。使用后备 `getConf` 完成认证并收到真实 `DANMU_MSG`；不是只确认 TCP/WebSocket 已连接。证据分别在 `live-room-network.json` 与 `live-room-network-auth.json`，原生视频帧为 `live-room-network-frame.png`。前期失败的原因包括低完整性测试宿主无法读取系统证书，以及新弹幕入口返回 -352；现已恢复本地测试宿主完整性并使用公开播放器后备接口，未关闭 TLS 证书校验。

未主动向真实账号或房间执行写操作。SC 的真实付费事件不由测试制造；多设备触摸、长时间高流量直播和全部 CDN/显卡仍需实际使用验证。

# BiliTouch 0.2.2

- 评论横图查看器分配更多空间；适应窗口支持放大小图，上一张/下一张移到图片左右两侧，保存与关闭移到边角。
- 经典布局中，评论区原位展开的竖图不再占用鼠标滚轮，滚轮继续滚动评论；独立看图区域仍可缩放。
- 移除取消收藏、取消点赞、稍后再看、关注切换的常规成功浮字，保留错误提示与按钮状态反馈。
- 我的、设置和消息子菜单统一采用首页的文字标签与滑动短下划线。
- 首页搜索框使用无系统边框模板、收起后折叠内容层，透明页头使用灰度文字并在交互时重绘，处理搜索伸缩及标签悬停的黑色条状残影。
- 修复网页布局小窗往返后左上角出现缩小视频画面：关闭 VLC 抓帧附带的缩略预览。
- 动态正文 BV 视频链接可直接原生播放，补充封面、标题与 UP 预览；保留图文原动态和其评论、点赞对象。元数据查询限制并发并复用成功缓存，失败时仍可点标题播放。
- 星引擎装扮下，在侧栏应用图标下方增加指定的 LandShop_00.png 网站入口，点击后用应用内浏览器打开 https://xteamparty.com/ 。其他装扮下隐藏。

验证：WPF 定向交互与渲染、动态解析、图片/字体/音轨、网页播放器停靠、主题和消息回归；对官方星穹铁道 PV 执行只读视频元数据与封面加载检查。setup 提取载荷与发布目录逐文件核验，便携版与安装器载荷分别检查原生播放器起播、播放时钟及实验性增强状态。

桌面电脑工具运行时初始化失败，未实施人工鼠标悬停或硬件触控板复测；黑色残影的所有显卡驱动组合仍需实际使用反馈。验证记录随包提供，未将自动渲染检查冒充人工桌面验收。

# touch.6：评论详情返回后触屏拖不动（2026-11-04）

版本 1.5.4-touch.6，源码 `BiliTouch-touch`，产物在上级 `dist/BiliTouch-1.5.4-touch.6`。

## 用户报的问题

> 视频播放详情页，点进具体评论后再点出来，评论呈现展开状态，触屏就无法上下拖动了。

## 复现

探针 `--probe-comment-chain`（`tests/TouchTests/CommentTouchChainProbe.cs`）走真实触摸事件链：

```
基线一次竖滑:            0 → 2085   ✅ 正常
进入评论详情:            Scrollable=0(内容变短, 正常)
返回列表:               PanningMode=VerticalFirst, Extent=2801, 布局数值全部正常
返回后一次竖滑(从顶部):  0 → 0      ❌ 完全不动
返回后反向竖滑:          0 → 0      ❌ 两个方向都不动
TouchSupport 状态:      _touchViewer 残留
```

**布局层面完全正常**（PanningMode、ScrollableHeight、Extent、PageHost 高度都对）。
所以问题不在"高度被压死"或"可见性没恢复"，而在**触摸事件被谁吃掉了**。

## 根因（两个，叠加）

### ① 捕获时机过早，吃掉了原生平移（主因）

`PlayerWindow.PageSwipe.cs` 的 `OnInfoTouchDownCapture` 原来是：

```csharp
if (_infoSwipeArmed) InfoPanel.CaptureTouch(e.TouchDevice);   // 一按下就抢
```

触摸捕获是**排他**的：`InfoPanel` 一抓住这只手指，内层 `ScrollViewer` 就再也收不到
Manipulation，`PanningMode` 完全失效 —— 手指竖着滑，列表纹丝不动。

为什么平时"好像能滚"？因为多数竖滑的起手点落在视频卡片/按钮上，那些元素在
`InfoSwipeAllowed` 里被判为不可抢；而**从评论详情返回**之后，起手点很容易落在
刚恢复的 `CommentList` 空白/文字区域上，于是每次都被捕获，看起来就是"整块拖不动了"。

**修法**：按下时**不抢**，等 `InfoMove` 判出"这是横向翻页"之后再抢。

```csharp
// 按下：只记住这只手指，不捕获
_pendingCaptureDevice = e.TouchDevice;

// InfoMove 里，判定为横向之后才捕获
if (_pendingCaptureDevice != null)
{
    try { InfoPanel.CaptureTouch(_pendingCaptureDevice); } catch { }
    _pendingCaptureDevice = null;
}
```

横向仍然要捕获（手指会滑出面板落到视频那块独立 HWND 上，不捕获就收不到后续 Move/Up）；
竖向从一开始就留给 `ScrollViewer` 的原生平移，互不干扰。

### ② 触摸状态残留

`TouchSupport` 的 `_touchViewer` 记的是**最内层** `ScrollViewer`，而清理条件是：

```csharp
if (ReferenceEquals(_touchViewer, viewer)) ClearTouchPanning();   // 只清记录的那个
```

页面一切换（进详情时 `CommentList` 被 `Collapsed`），那个内层 viewer 就**再也收不到
`TouchUp`** —— 它已经不在有效可视路径上。于是 `_touchViewer` 永久残留，
`IsTouchPanning(...)` 一直为 true，页面据此认为"手指还在滚动"，推迟所有会改变
滚动内容的工作。

**修法**：手指抬起是**全局**事件，任何 viewer 收到 Up 都说明这次触摸结束了，无条件清空。
`IsTouchPanning` 超时后也主动清残留，不只返回 false。

## 验证

| 项 | 修复前 | 修复后 |
|---|---|---|
| 基线竖滑 | 0 → 2085 | 0 → 1207 |
| 返回后从顶部下滑 | **0 → 0** ❌ | **0 → 2085** ✅ |
| 返回后反向竖滑 | **0 → 0** ❌ | **2085 → 0** ✅ |
| `_touchViewer` 残留 | 残留 | null ✅ |

回归：**触控与 VLC 74 项全过**（含左右翻页手势、触控板翻页、滚轮切页），
**动态/首页/我的页 99 项全过**，真实动态流心跳 p95 35.2ms。

# BiliTouch 0.3.1

本版重点改善高分辨率播放开销与基础功能稳定性。

- 视频解码设置新增可用显卡选择、自动模式和软件兼容模式，更改后重启生效；播放后可查看实际硬解设备。显卡断开或不支持当前视频时自动回退。
- 常规 8-bit 视频采用 NV12、显卡颜色转换和共享纹理合成，减少大块 RGB 数据的转换与上传。保留片源解码分辨率，显卡按实际显示像素缩放；窗口、圆角和连续变形继续支持。高位深及 HDR 内容保留兼容颜色转换。
- 最小化播放器时停止持续上传视频画面，保留声音和播放时钟；恢复后显示最新帧。
- 换片、切画质/音质、听视频切换和进度恢复中的原生停止操作移到后台串行执行，防止快速切换时旧请求覆盖新请求。
- 登录完成改为异步等待设备资料保存，避免首次登录或网络较慢时卡住界面。
- 收藏清空及批量移出固定操作目标和账号；切换账号后清除私信、联系人、草稿及通知，作废旧账号在途响应；修复收藏夹响应混入和分页失败后跳页。
- 修复请求重试签名、音质偏好读取与未读角标状态；首页封面按所需尺寸复用缓存，减少重复加载，保留视频进入与返回动效。
- 画质增强控制栏按当前播放方式显示真实可用状态。点播暂不支持厂商超分及 HDR 增强，显卡解码与合成正常启用；直播的实验性增强保留。
- 保留现有搜索界面及滚动方式。
- 修复失效的滚动统计与动效验证，自动构建执行账号、设置、限流、视频缓冲和滚动边界检查。

本机已验证 Intel 与 NVIDIA 实际硬解、软件兼容模式、重复换片、最小化恢复、暂停缩放，以及基础功能和动效回归。性能测量为本机短时对照，不能作为所有设备或所有片源的帧率承诺。

安装器包含程序及播放依赖。源码随版本标签提供；下载附件仅上传一个 setup.exe。

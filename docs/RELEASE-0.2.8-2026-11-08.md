# 0.2.8 首页封面与网页视频过渡修复（2026-11-08）

## 最终改动

- 首页缓存命中先于视口图片队列执行；同 URL 已有更大缩略图时复用，避免较窄卡片再解码。以条目弱键记录已显示的封面，缓存淘汰后的读盘恢复也不重播入场动画。保留 32 MiB 内存预算及卡片虚拟化。
- 网页视频大小窗过渡从截图准备阶段隐藏弹幕，原生视频稳定后恢复；取消与备用动画沿用同一显示规则。
- 先完成右侧占位的布局再读取目标坐标，起点采用视频实际位置，消除旧上边距与新上边距之间的二次位移。
- 截图窗口先跨过两个不同的渲染时间戳并等待 DWM 提交，再隐藏原生视频。结束时先完成隐藏视频的目标布局和宿主黑底处理，再显示视频；截图保持在原生浮层之上，等待稳定与渲染提交后直接撤掉，移除整层透明度淡出造成的交接混合。取消时唤醒等待并清除渲染订阅。
- AppVersion、程序集版本、安装器、发布脚本默认值、README 与下载索引同步为 0.2.8。

## 验证

Release 构建成功。10 组回归共 **284 项**：封面复用 10、首页/版本 9、屏幕取样 5、网页布局 31、控制栏/未读 41、弹幕恢复 13、动态 119、触控板 33、评论滚动 12、控件创建 11。逐组结果见本地 `artifacts/release028-regressions.json`。

纯色本地视频在真实原生播放器中连续做三次缩小、三次还原。最终 Release 轮次在视频中心取得 299 次桌面像素样本（248 次处于截图窗口存在且布局有效的阶段），没有异常颜色；取样使用 DWM 同步以减少“读取下一帧几何、却采到上一帧屏幕”的测量误差。此结果覆盖本机此夹具的中心像素，不代表整个画面逐像素、所有显卡、多屏 DPI 或所有负载下绝无闪烁。布局回归同时比较截图画面落点、真实视频落点和 250ms 后位置，纵向差异小于 1 DIP。

仍有既存编译警告。原生纯色夹具在关闭时输出 H.264 缓冲释放诊断，测试进程成功退出；这些诊断未计作画面正常的证据。初次并行构建负载下，固定等待 1200ms 的还原检查未等到完成；改为有上限地等待真实过渡状态结束，最终回归全部通过。

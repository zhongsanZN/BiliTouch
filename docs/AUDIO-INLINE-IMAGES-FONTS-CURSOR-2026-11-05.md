# 高级音质、评论原位看图、字体与鼠标（2026-11-05）

本轮仅修改和验证源码，版本仍为 0.1.2，没有更新 dist 中的安装包。

## 高级音质

修正了三个会让界面选择与实际音轨不符的入口：

- `dash.flac.audio` 为单对象时曾被忽略。现在兼容对象/数组，也支持杜比对象/数组以及 `base_url`、`backup_url` 字段；同档按码率择优。
- 720P 及以下在自动音质下不再提前走普通音视频合流地址，从而能够选中该视频实际提供的 FLAC/杜比音轨。明确的标准音质仍可走旧合流路径。
- 短视频缓存加入实际音质维度，缓存格式升级为 v5，避免旧 AAC 合流文件冒充新选中的 Hi-Res。重编码没有加入合流过程，音频样本仍是原始拷贝。

切换音质时同时更新重播和听视频的音源、保留续播位置、取消旧预取，并保存偏好。请求代次变化后不再把旧取流结果写入当前视频。

真实账号只读核对日志为 `artifacts/premium-audio-live.log`：

- BV1DB4y1x7A9：1080P、720P 都选中 HiRes / fLaC。
- BV1E8xNzbEtd：两档画质都选中 HiRes / fLaC；同时具有 Dolby / ec-3，明确选择杜比后返回 Dolby。
- BV1Me411L7N5：当前响应只有普通音轨，按实际结果选 High，没有伪造高级标识。

另用 96 kHz / 24-bit 静音 FLAC 分片 MP4 检查打包内核。VLC MP4 静态轨道元数据报告的采样率为 48 kHz，但解码输出回调实际协商为 **96 kHz**，并收到 PCM 样本；因此验证不只依赖静态元数据或徽标。该检查使用内存音频输出，不产生系统声音。产品播放器本身也通过同一路取流/切换流程播放了本地视频与 FLAC 从音轨，验证重播、听视频地址同步更新。

上述结果不代表系统音频设备开启了独占或无重采样输出；本轮没有改变系统音频设备配置，也没有扩展账号或稿件本身的音轨权限。

## 评论图片

- 原布局：视频靠顶部排列，把原先上下留白占据的区域用于下方的原生看图器。支持图片切换、鼠标滚轮缩放、拖动、触摸缩放/平移、复位与保存。关闭后恢复视频原布局。
- 网页布局：**在点中的缩略图单元格原位展开**，展开时隐藏该缩略图，不保留第二份缩略图，也不另加一个下方预览面板。使用无外框、无工具栏的图片呈现，右上角可收起。
- 切换布局时沿用同一个图片查看器；全屏退出后恢复。换视频、关闭图片或退出评论详情时清理图片和请求代次。
- 视频仍沿用同一个 VideoView / MediaPlayer，没有为看图重新挂载视频或新增窗口。
- 网页视频停靠改为越过阈值后完成整段运动，避免停滚后停在两列之间遮挡内容。首个可绘制帧才开始计时，帧间推进设上限，避免首次重排较慢时直接跳到终点。

## 字体与鼠标

设置 → 通用新增应用字体：系统默认、HarmonyOS Sans、荆南波波黑。即时应用到现有窗口和弹幕；弹幕切换字体后清理旧尺寸的泳道记录。原生视频浮层、菜单和提示也引用应用字体资源。图标字体、评论 emoji 的安全字体路径保留。

HarmonyOS Sans SC Regular/Bold 取自华为官方字体包，文件未修改；许可原文随资源和输出保存，设置页显示字体使用声明。荆南波波黑使用用户给定目录中的 Bold TTF，未修改，也不要求用户在系统中安装字体。来源见 `BiliTouch/Assets/Fonts/SOURCES.md`。

鼠标使用用户提供的 `Cursor_up.png` 和 `Cursor_down.png`，将原始 PNG 原样封装为原生 CUR：粉色常态、蓝色按下态，热点统一为 (8,7)。仅改变本应用指针，不更改 Windows 全局设置。文字编辑、调整尺寸、视频隐藏鼠标等用途保留。应用内 WebView2 页面同样注入对应指针与按下反馈，并保留文字/尺寸光标。

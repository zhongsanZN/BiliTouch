# 0.3.1 播放性能与基础体验修复

对应 [基础体验审查](EXPERIENCE-PERFORMANCE-REVIEW-2026-11-11.md) 和 [基础能力修复](FOUNDATION-FIXES-2026-11-11.md)。本版整合当前工作树已有的基础功能、封面及进入动画修改；搜索页面按用户反馈保留现有实现。

## 视频输出与显卡选择

常规 8-bit 4:2:0 视频使用 NV12 内存帧、D3D11 视频处理器颜色转换、D3D9Ex 共享表面和 WPF D3DImage。解码仍按原片源分辨率进行，显示表面按实际 DPI 和显示尺寸在显卡缩放，保留精确宽高比。布局缩放延迟合并，暂停时也能更新最后一帧。圆角、网页布局与连续变形保持在 WPF 合成树内。

NV12 比 RGB32 的系统内存帧小约 62.5%；不再每帧在界面线程把整幅 RGB 数据复制到 WriteableBitmap。GPU 完成信号通知界面提交，不用计时器轮询 GPU。D3DImage 超时锁也正确配对 Unlock，避免图像在几帧后停止更新。高位深、HDR 档位、非 4:2:0 格式、软件界面渲染及不支持共享合成的设备保留兼容路径；显卡运行中失效时也保留当前帧的兼容转换。

这仍包含 VLC 显存读回和 NV12 上传，并非全程零拷贝。没有用降低片源清晰度或替换连续变形效果取得性能数字。

播放设置按 DXGI 设备列出具有 D3D11 视频解码配置的显卡，提供自动与软件兼容选项，保存后重启生效，并显示实际解码设备。当前 LibVLC 3.0.24 没有公开的任意显卡参数，选择在它创建 D3D11 设备时指定 DXGI adapter：只改进程内、随包 VLC 模块的 GetProcAddress 导入，转发到系统 D3D11CreateDevice；解码设备及引用仍由 VLC 正常管理，不修改显卡系统设置或磁盘 DLL。VLC 依赖固定版本，升级时必须重跑手动显卡及重复换片检查。

已验证 Intel Arc B390 和 NVIDIA RTX 3080 的真实 D3D11VA 日志、反复换片和软件模式。没有采用传入外部 winrt-d3dcontext 的方案；该方案在当前内核中存在跨次停止的引用失衡。

## 本机测量

Core Ultra X7 358H、16 逻辑处理器、225% DPI，本地动态夹具。数字是短时采样；帧交付、合成提交及显示器最终呈现是不同指标。

| 条件 | 合成提交/秒 | CPU 毫秒/秒 |
| --- | ---: | ---: |
| 完整播放器，同一 H.264 4K60，兼容 RGB 对照、前台窗口 | 41.3 | 1259 |
| 完整播放器，H.264 4K60，新路径、前台窗口 | 58.1 | 928 |
| 完整播放器，新路径另一轮 | 59.6 | 802 |
| 单独视频控件，HEVC 4K60，新路径 | 60.0 | 437 |
| 单独视频控件，AV1 4K60，新路径 | 60.1 | 461 |

1000 CPU 毫秒/秒等于一个逻辑核心持续工作，不是全机 CPU 占用 100%。前台完整窗口一组对照减少约 26% CPU 时间；另一轮窗口环境不同，不能合并为所有设备的统一提升比例。相较原审查中的完整窗口，上传稳定性及 CPU 开销均有改善，仍不承诺所有 4K 内容固定 60 fps。

最小化时持续上传为 0，播放时钟继续推进；一轮 CPU 约 259 毫秒/秒。恢复播放及暂停缩放检查通过。主线程换片入口从原审查约 99–255 ms 改为本地测量约 2–3 ms 返回，原生停止仍需要时间，但已移出界面线程。

BT.709 4K 色条与 FFmpeg 解码参考比较：28 个内部采样点最大通道误差为 2；原兼容路径同组最大差为 35。该结果覆盖标准 SDR 色条，不作为全部色彩空间或 HDR 的验收。

## 功能和检查修复

- 登录完成异步等待设备资料保存；重复完成有防重入保护，窗口已关闭或账号变化后不继续提交界面结果。
- 原生停止与后续播放提交串行化，快速切换作废旧操作，关闭时等待同一队列；切画质及音质也按视频代次校验响应与收尾状态。
- 最小化及隐藏不再持续上传；GPU 完成事件与视图销毁、旧格式清理互相隔离，恢复时提交最新帧。
- 画质增强按钮按实际点播能力禁用并说明原因，直播实验性增强保留；不再把设置里的“开启”当作厂商超分已执行。
- 修复滚动探针没有加入帧间隔、没有订阅偏移变化的问题。修复动效测试的隐藏视图及旧缓冲指针假设，测试宿主使用实际 WPF 同步上下文；停止等待不再依赖固定睡眠。
- 滚动取消会替换已排队的偏移，包括小于 0.01 DIP 的残留；完整边界序列通过。
- 账号隔离、收藏目标冻结、失败分页重试、私信状态和音质保存读取修复纳入本版，原基础四组 94 项断言通过。

验证入口包括 foundation、rate-limit、message-unread、mine-messages、decoder-settings、vmem-buffers、motion-performance、scroll-boundaries、player-lifecycle、player-comments-scroll、vmem-player、vmem-view、decoder-hardware 及逐编码性能夹具。自动工作流运行可独立执行的基础、限流、设置、缓冲、未读和滚动边界组；实体显卡和本地媒体的专项检查在发布机执行。

构建、每组检查、颜色参考、GPU 引擎样本和安装器验证记录位于 `artifacts/release-0.3.1/`。测试使用隔离资料目录，不执行真实账号删除或发送私信。部分 H.264 停止时仍会输出 get_buffer/no frame 信息，专项检查的画面推进及退出码均有单独记录，没有把这些日志删掉当作已消除的问题。

尚未以这轮短测证明长时功耗、全场景物理触摸、所有 HDR/全范围色彩片源或所有外接显卡组合。完整首页仍有抓屏长间隔和冷封面回收压力；本版恢复了可信统计，没有把独立控件通过等同于全站达到 120 Hz。

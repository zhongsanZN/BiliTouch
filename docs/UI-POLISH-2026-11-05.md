# BiliTouch 首页、动态和播放器调整（2026-11-05）

## 打包边界

先生成 BiliTouch 0.1.1 修改前快照，再修改本轮界面。`../dist/` 中的安装器、桌面压缩包和源码压缩包包含上一轮个人主页、手势及缓存改造，不包含本文记录的后续修改。没有再次打包；工作区源码保持可继续修改。

- 安装器：`BiliTouch-0.1.1-setup.exe`
- 桌面压缩包：`BiliTouch-0.1.1-desktop.zip`
- 对应源码：`BiliTouch-0.1.1-source.zip`，逐文件 SHA-256 见 `artifacts/package-0.1.1-source-manifest.json`。
- 使用 .NET 10 Windows Desktop Runtime；内部程序集名称维持 BiliTouch。

## 首页与边栏

首页刷新移到页头右侧，与动态页刷新使用相同外边距和位置。首页浮动工具栏移除主题切换和私信入口；两个入口放到主窗口左下侧栏，保留 44 DIP 点击区域，跨页面可用。

## 动态卡片与详情

- 转发复用视频详情的分享路径、描边和尺寸，点赞复用同一几何和尺寸。
- 删除卡片操作行最右侧的复制链接按钮；原有右键菜单仍可复制链接。
- 评论首批请求 3 页，正常每页 20 条；接近底部自动再请求 2 页。失败显示重试，去重且遇到重复空页停止续载。
- 删除手动加载更多按钮和原先预留底部状态区。评论加载提示放在评论标题旁；无状态和错误时不占位。
- 输入框只占右评论栏底部，普通状态不显示“发表评论”标题；回复/转发时才显示目标提示。保留 Ctrl+Enter 发送。

## 播放器

- 删除右栏重复的稍后再看，只保留顶部栏入口并同步状态、提示和动画。
- UP 信息改为横跨右栏的三列：40 DIP 头像、可省略长名称与主页入口、关注按钮。
- 删除未经要求添加的画面缩放和 LibVLC Scale 写入。视频区的触控板 Ctrl+滚轮缩放输入现在对应全屏：正向张开进入，反向捏合退出；小 delta 累计，单次输入流只执行一次，不改变音量。
- 全屏入口保存原窗口状态和 RestoreBounds。退出时刷新普通窗口样式和工作区，再恢复原窗口位置、尺寸及最大化状态。触屏、触控板、按钮和键盘共用此恢复路径。

## 验证

- `--ui-polish`：27 项通过，包含刷新坐标、侧栏位置、60 条首批评论、自动续载、输入框布局、共用图标、重复入口删除、长 UP 名称与窗口全屏往返。
- 动态回归：112 项通过；“我的”回归：33 项通过；BiliTouch 回归：19 项通过。
- 播放器及真实触摸事件链：73 项通过，包含从最大化进入全屏并通过触屏捏合恢复最大化。总计 264 项通过。记录：`artifacts/ui-regression-player.log`。
- 播放器首跑在既有单击显隐控件的计时检查中偶发失败，未改该逻辑，原样复跑通过；首跑记录保留为 `ui-regression-player-first-attempt.log`。VLC 仍输出沙箱内任务栏缩略图权限警告，静音样片播放和断言通过。
- 截图：`artifacts/touch-tests/ui-*.png`，覆盖亮/暗主题、窄窗口、右栏作者布局。使用受控评论数据，不是用户账号内容。
- 未进行真实触控板/触屏设备长时间手动验收；媒体检查使用静音本地样片。网络接口行为仍以实际服务端响应为准。

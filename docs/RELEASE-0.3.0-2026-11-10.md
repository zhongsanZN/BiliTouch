# BiliTouch 0.3.0 本地核对版

状态：本地构建，等待用户核对；尚未发布 GitHub Release，也未推送版本标签。

## 本次变化

- 视频详情从被点击的视频卡片展开，关闭时收回原卡片。先让卡片过渡画面真正上屏，再显示播放器窗口，避免 Windows 的原生窗口首帧抢先从屏幕中央出现。兼容播放器预热和首次打开。
- 补修真实环境中的 Windhawk Mobile Open Animation 冲突：该扩展会绕过 DWM 过渡设置，额外创建带应用图标的启动面板。详情及过渡层在进入期间临时归属源窗口，让扩展识别为应用内部窗口；完成后恢复原窗口归属。没有修改 Windhawk 配置。同时按实际屏幕范围计算过渡层尺寸，包含 110% 界面缩放。
- 连续点击只处理最后一次播放请求；展开途中关闭从当前画面转向收回，清理临时过渡窗口。
- 侧栏消息入口显示未读角标，私信、回复与 @、收到的喜欢显示对应未读数。启动、窗口重新激活、阅读消息后刷新，后台每 45 秒更新；退出登录清空计数，忽略旧账号的迟到响应。请求失败保留最近一次确认的计数。
- 未读数字明确使用应用文字字体，避免继承图标按钮字体后变成方框；已检查单个数字、两位数字和 `99+`。
- 保留本轮已核对的播放与封面优化：默认启用 WPF 视频合成并移除设置开关，恢复硬件解码，减少视频帧复制和无效刷新，修正小封面缓存被放大复用导致的模糊。详情见 `VIDEO-AND-COVER-PERFORMANCE-2026-11-10.md`。

## 验证记录

- 独立构建配置 `Release030`，显式启用优化，避免覆盖正在运行的旧版预览。构建成功，无编译错误。
- 实际首页合成时钟测试：网页布局首次打开 15 项、普通布局预热后打开 15 项，通过。覆盖原卡片位置首帧、显示顺序、110% 缩放尺寸、临时窗口归属及还原、正常收回、连续点击、途中关闭和临时窗口释放。
- 最终网页布局回归增加展开途中关闭源窗口，17 项通过，播放器和过渡层均清理完成且没有新增应用异常。
- 首轮使用置顶的简化窗口测试，漏掉了用户环境的启动动画冲突，首轮录制不能作为真实首页已修复的结论。补测采用真实 MainWindow、HomePage、可见 VideoCard、110% 界面缩放、相同 DPI 清单，取消测试窗口置顶。保留 Windhawk 扩展开启，实际桌面录制确认卡片展开过程不再出现居中的黑色图标面板。录制：`artifacts/release-0.3.0/real-home-after.mp4`。
- 未读服务与实际侧栏绑定、数字字形 14 项、消息页 37 项，通过。登录账号的只读接口检查 2 项通过，能取得私信、回复、@ 和喜欢计数；未发送测试消息。
- 视频合成与形变 20 项、封面缓存复用 17 项、首页预加载 19 项，通过。
- 最终安装器解出 273 个载荷文件，与打包输入逐个 SHA-256 相同。安装器解出的程序、安装器输入程序（网页布局）和解压后的便携程序均通过 3840 像素宽视频起播检查，播放时间前进且合成画面持续提交。

## 核对范围

桌面录制使用本机真实首页控件与测试内容；没有覆盖不同缩放的多显示器组合。未在真实账号上制造新消息或跨端已读事件。在线视频内容和账号消息体验仍待用户在更新后的安装包中核对。

安装器载荷校验、起播结果及产物校验值保存在 `artifacts/release-0.3.0`。安装包为 `Publish/BiliTouch-0.3.0-setup.exe`；便携包仅保留在本地，未上传。

用户反馈后的重建校验使用 `artifacts/release-0.3.0/followup`，当前安装包的校验值记录在 `artifacts/release-0.3.0/sha256.json`，覆盖首轮构建记录。

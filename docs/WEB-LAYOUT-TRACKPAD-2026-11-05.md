# 网页视频布局与触控板信息流（2026-11-05）

当前修改仅在源码和本地验证构建中，未重新制作安装包。BiliTouch 版本仍为 0.1.2；dist 的旧安装包不包含本轮修改。

## 设置入口与行为

- 设置 → 通用 → 触控板：信息流滚动灵敏度，25%～175%，默认 75%，每档 5%。即时生效并持久化。覆盖首页、动态、我的子模块、搜索、分区、个人空间中的纵向信息流；普通鼠标整格滚轮保留原有步长，播放器音量/进度操作不使用该灵敏度。（本段的"只覆盖信息流、整格另算"已由 0.2.6 取代：该开关现在作用于全部滚动容器，见 `RELEASE-0.2.6-2026-11-07.md`。）
- 设置 → 通用 → 视频详情：并排布局（默认）/ 网页布局（备用）。可即时切换，重启后保留选择。
- 网页布局中评论在视频下方，右侧依次为 UP/标题/数据/操作、视频停靠位置、简介及选集/相关推荐。
- 向上浏览评论时，视频平滑进入分享、下载下方的右侧位置。返回顶部恢复大视频；紧凑控制栏提供播放暂停、返回顶部和全屏。
- 同一个 VideoView、MediaPlayer 与评论树持续使用，移动过程中不换源、不重建播放器、不新增独立小窗。
- 全屏、铺满窗口、直播及听视频模式沿用原来的完整视频区域；退出后恢复网页布局及评论阅读位置。界面缩放使用真实停靠坐标；宽矮窗口限制主视频高度，避免控制栏落在可见区域外。

## 滚动与保存实现

TrackpadScroll 接管最内层可滚动视口的精细滚轮输入。累积所有输入距离，每显示帧至多提交一次位置更新，不为每个输入包新建动画时钟。短缓动跟随目标，不额外合成系统惯性。页面卸载、触摸/笔/鼠标接管及外部滚动会取消残留运动；静止后解除帧回调。

精细输入沿用小 delta 判定，并允许同一精细输入序列中的较大 delta。WPF 滚轮事件本身不能在这条路径里可靠区分所有设备；高精度鼠标滚轮的小 delta 也会走精细输入路径。传统独立 ±120 整格保持原语义。

保留信息流的回收虚拟化，不通过扩大保留卡片数量换取表面流畅。验证样本在 175% 灵敏度下输入 240 个数据包，合并为 76 次位置更新，4000 条列表仅保留 17 个条目容器。这是受控样本的工作量记录，不代表所有设备、网络图片和真实动态内容都能保持固定帧率。

快速拖动滑块还暴露了 SettingsStore 的异步写入竞态：旧任务在版本检查之后可能覆盖同步保存的新值。现将实际写盘序列化，并在写盘锁内再次校验版本；退出 Flush 等待最后的快照。返回顶部动画的取消也会覆盖已排队的旧滚动请求，并使过期完成回调失效。

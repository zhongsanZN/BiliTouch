# BiliTouch 0.1.5

包含 0.1.4 的全部修订，以及独立直播间的第一版完整实现。

- 0.1.4 已按顺序先行封存，包与源码快照保留在父目录 `dist/BiliTouch-0.1.4`。
- 本版直播入口打开独立窗口，移除点播时间轴、简介/评论、三连等布局。
- 实时画面弹幕、独立聊天侧栏、发送弹幕、历史发言、手动阅读与返回最新、全局弹幕偏好与关键词屏蔽。
- SC 金额/用户/内容置顶、倒计时、去重、到期、撤回及乱序删除处理；没有购买、礼物或打赏控件。
- 主播/标题/分区/公告/关注、实际清晰度、音量、静音、全屏、重新连接、开播/下播与房间状态更新。
- 断线重连、公开弹幕配置后备、有限队列、分批 UI 更新、容器回收、关闭时释放原生资源。
- 修正清晰度控件深色时的文字对比与控制栏双击误触全屏。临时目录不可写时光标回退为系统箭头，避免鼠标移动触发异常。

版本已在 AppVersion、csproj、安装器、发布脚本和根 README 同步为 0.1.5。

本轮定向检查共 196 项通过：直播间 42、星引擎主题 28、播放器/信息流收尾 25、界面 50、滚动 24、网页式播放器 27。安装器脚本明确保存为带 BOM 的 UTF-8，避免编译器将中文载荷目录按本地代码页误读。便携版与安装版均校验文件版本；便携版的三份 WPF 原生库均为 .NET 10。

验证与实现记录见 `LIVE-ROOM-REBUILD-2026-11-05.md`。真实直播在游客与现有登录态下都已通过只读画面播放及弹幕接收；没有发送真实弹幕、关注或支付。SC 的真实付费事件没有主动制造，以协议/界面夹具验证；多设备触摸及长时间高流量直播尚需使用反馈。

本地打包，不上传远程发布。主题美术与代码权利分别见 `BiliTouch/Assets/Skins/StarParty/SOURCES.md` 和 `LICENSE`。

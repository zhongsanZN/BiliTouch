# BiliTouch 0.2.3

- 修正默认装扮下首页分区图标的尺寸、缩放和居中；星引擎装扮继续使用较大的原始拼图图标。
- 设置、消息接入共用模块手势：触屏横滑跟手切页，纵滑保留内容滚动；触控板横向消息经主窗口转发，单次连续手势只切一页；标签上可用滚轮切换，鼠标前后侧键可切换模块。滑杆、输入框、调色盘等控件不被触屏切页抢占。
- 图片展开默认适应可用区域，移除左下角的原尺寸/适应窗口按钮。
- 移除简介/评论右侧遗留的分 P 入口，分 P 使用自己的展开区和收起按钮，显示在合集上方，单 P 视频隐藏整区。
- 动态点赞改用 JSON 正文、查询参数中的 CSRF 和数值动作；取消点赞明确发送 2，避免把取消写成切换动作 0。该变更以请求构造测试验证，没有替用户实际点赞。
- 弹幕不再按时间排序后只保留前 6000 条。正常上限提高到 60000，超过上限时均匀覆盖完整时间轴；每段独立计时，失败后重试一次，避免后面排队的段被统一超时提前取消；换片取消旧读取并校验加载代次。

验证：新增 33 项定向检查，覆盖触屏方向仲裁、触控板原生消息、滚轮分流、侧键、默认分区图标、分 P 布局、点赞请求和弹幕分段重试；相关回归合计 288 项通过。匿名只读实测从本机播放记录选取的视频，返回弹幕覆盖至末尾；这不等于复现或排除了所有登录状态下的偶发弹幕消失。桌面电脑工具运行时不可用，未实施物理触控板/触屏人工验收。

setup 提取载荷逐文件比对，安装器载荷和便携版分别验证真实视频起播与时钟推进。源码、二进制、许可和校验值随版本提供。

# BiliTouch 0.1.4

本版封存主题与播放器修订，直播间重做在此快照之后进行，不混入本版源代码包。

- 星引擎party闪亮启航主题：首页/侧栏纹样、单条连续黄边、左实右透明延展、裁切铺满的个人页双人图、操作角色反馈。
- 点赞＝紫发爱心角色，收藏＝蓝发兔耳角色，投币＝船长；成功不重复出现右上角文字提示。
- 视频评论在详情到达后预加载，切页复用结果及在途请求。
- 视频弹幕发送、失败草稿保留、重复提交保护；弹幕图标开关与“弹幕设置”文字入口。
- 控制栏保持单行，弹幕编辑器压缩至同一行；输入时不自动隐藏控制栏。
- 全屏移除中间 Normal 窗口状态；网页布局移动视频时使用 BiliTouch 品牌过渡遮挡原生表面重置。
- 滚动基准减半：触控板、手指平移及普通滚轮。连续输入按帧合并，封面按视口预取。

版本已在 csproj、AppVersion、安装器、发布脚本及根 README 同步为 0.1.4。

验证：新增功能/本轮反馈 25 项、主题 28 项、界面 50 项、滚动 24 项、网页式播放器 27 项，共 154 项通过。记录为 `artifacts/release-0.1.4-*.log`。五格普通滚轮累计 450.0 DIP；180 卡片夹具首屏只启动附近 6 张封面任务。真实硬件滚动手感、所有显卡及真实账号弹幕发送尚需线上体验确认；测试不向真实账号发弹幕。

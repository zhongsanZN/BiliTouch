# 首页和评论区滚动排查

本次比较了 0.2.6、当前工作树和本地优化预览。首页的主要收益出现在滚进新一行时。两处评论区的正文创建成本也下降了。连续滚动时的帧间隔仍然波动，尤其是动态评论和播放中的视频评论，不能由一项布局测试推断整页流畅度。

## 现场线索

改动前，用同一组精密滚轮事件驱动首页卡片墙、动态卡片和三种评论视口，最终位移都是 151.2 DIP。第一次采样中，首页和动态评论的渲染回调间隔 P95 分别是 29.8 和 30.1 ms，动态卡片是 11.4 ms。后续重复运行时，动态卡片也会出现长帧。位移标定已经统一，平均速度解释不了页面之间全部的手感差异。

## 首页跨行

卡片墙已经虚拟化。跨行时，新增的 VideoCard 原先会构建六个菜单项、各自的图标和分隔线，并创建本地样式。影之刃零的播放量图标还会在测量、绘制时把两个几何对象序列化成字符串进行比较。图片已经在磁盘缓存、但尚未解码时，每次请求还会在调用线程检查文件，之后才把解码派到后台。

- 卡片菜单改到首次打开时创建。右键和更多按钮共用同一个菜单，收藏夹等页面的追加操作在打开时取当前值。
- 所有视频卡复用同一组样式和播放图形。卡片墙用生成器位置取条目索引，只在尺寸改变时写入继承属性。
- 图片缓存未命中时，先在锁内登记任务，再由工作线程探测磁盘、下载或解码。同一 URL 和解码档位的并发请求复用该任务。内存命中的封面去掉了一次 UI 队列往返。

在 216 DPI（225%）下，使用影之刃零主题、180 条不同缓存键的视频和本地实图。窗口为 1180 × 780 DIP，每次向下跨 260 DIP，连续 32 次。旧版取本地 0.2.6 安装器载荷中的 DLL。两个版本使用同一测试程序，三轮交替启动新进程。表中记录滚动命令和同步布局的耗时。

|轮次|旧版中位数|预览版中位数|旧版 P95|预览版 P95|
|---|---:|---:|---:|---:|
|1|7.75 ms|2.99 ms|24.79 ms|8.15 ms|
|2|7.56 ms|3.16 ms|15.78 ms|9.67 ms|
|3|6.84 ms|2.03 ms|22.50 ms|7.27 ms|

最慢的一次布局仍达到 30.46 ms。后台解码和最终呈现没有计入同步布局计时。原始记录在 `artifacts/scroll-image-wall-*.log`，复测入口为 TouchTests 的 `--scroll-image-wall`，使用工作区 theme-research 下的官网截图。

## 视频评论和动态评论

动态详情采用会回收行的 ListBox，视频评论使用页面级 ScrollViewer 内的 ItemsControl。两者共用可选择文字的 CommentText。原先每次正文、回复前缀、前缀颜色或提及颜色变化都会整段重建流文档，连续绑定到位时重复创建段落、文字和表情。现在直接用目标文档创建编辑器，在下一次测量前统一应用这一轮变化。正文依然可拖选复制，楼中楼前缀和表情继续参与原有的文字排版。

网页播放器曾在每次纵向偏移变化时重算占位尺寸和视频边界，稳定停靠时也会重复执行。现在纯位移只比较停靠阈值，目标状态发生变化才启动过渡，视口尺寸变化仍重算布局。分栏和网页评论共用的只读正文内部视口明确让外层接管手势，回归测试从实际的文字 Run 发出滚轮事件，验证外层移动、正文内部偏移保持为零。

以每批 32 个新控件测量创建、首次测量和排列，预热后取五批中位数。分配量为当前 UI 线程累计分配。

|对象|旧版耗时|预览版耗时|旧版分配|预览版分配|
|---|---:|---:|---:|---:|
|视频卡片|116.2 ms|90.4 ms|8,738 KiB|6,712 KiB|
|含前缀和提及的评论正文|127.0 ms|103.7 ms|8,846 KiB|6,897 KiB|

该项覆盖回复正文创建，整条评论还有头像、按钮、图片和子回复。复测入口为 `--scroll-realization`。测试同时检查菜单第一次打开、重新打开、评论换绑、输入命中和加载圆环生命周期。

## 共享滚动和动画

精密输入以前每交付一次位移就注销渲染回调，下一批事件再注册。本次在短手势间隔内保留同一个回调和小数目标位置，新位移才写入视口，最后一个包后空闲 90 ms 即释放。滚轮刻度和触控板灵敏度继续沿用已有设置。另修复加载圆环在隐藏页或卸载后继续持有无限旋转时钟的问题。

连续滚动探针记录 WPF 渲染回调。用同一套脚本对照改动前和最后一轮的 P95 如下。每项约 1.5 秒，受系统调度、窗口合成和测试事件派发节奏影响。

|视口|改动前 P95|最后一轮 P95|
|---|---:|---:|
|首页卡片墙|23.9 ms|26.3 ms|
|动态详情评论|24.7 ms|25.4 ms|
|视频分栏评论|22.7 ms|26.3 ms|
|视频网页评论|23.9 ms|27.1 ms|
|动态卡片对照|10.5 ms|25.5 ms|

最后一轮各处的长帧仍然明显，动态卡片对照也比第一次慢。这个指标没有显示整体改善。首页跨行布局和评论创建的收益可在独立测试中观察到。测试未覆盖真实账号内容、物理手指到显示器的延迟，以及边播放高负载视频边滚动的持续表现。完整读数见 `artifacts/scroll-before-*.log` 和 `artifacts/scroll-verified-*.log`。

# BiliTouch 0.2.15 修复与发布验证 · 2026-11-09

本版包含上一轮网页版大小窗、帧队列和弹幕派发优化，以及本轮音量浮层、后台筛选与播放器生命周期修复。

## 音量浮层问题

此前仅延迟 350ms 关闭浮层，没有同时处理其父控制栏和独立 Popup 的生命周期：

- 点播的自动隐藏条件漏掉了音量与倍速面板。鼠标移入独立 Popup HWND 时，视频区收到 MouseLeave，父控制栏可能先收起并关闭音量。
- 只有面板 MouseLeave，没有移入取消旧关闭任务的处理。多次进出产生的旧延迟可能关闭新一轮操作。
- 触发按钮与面板之间的负偏移留下未命中的间隙；滑杆拖动到面板外也缺少捕获期间的保持条件。
- 直接拖动滑杆没有同步百分比和静音图标；跳转静音期间的音量入口提前返回，界面反馈可能停在旧值。

本版将面板打开状态加入父控制栏保持条件；点播、直播均监听面板移入/移出，使用单一可取消的 DispatcherTimer。透明底部通道覆盖原 10/8 DIP 间隙。鼠标捕获期间保持面板，释放后恢复延迟关闭，关闭窗口时停止计时。百分比与图标在音量偏好变化时立即同步，跳转期间保留目标音量。

新增 `popup-lifetime` 的 28 项覆盖点播/直播、实际屏幕几何、父控制栏边界事件、快速重新进入、最新关闭间隔、捕获拖动、释放、点击画面收起及关闭回收。测试在实际播放窗口上运行，enter/leave 和边界事件由回归程序发出。

## 性能及其他修复

1. 弹幕排序、规则编译和整库重筛移到后台。设置先取得不可变快照，按规则版本、媒体代次及 CID 验证结果；改规则、换片或关闭取消旧任务。
2. 外观调节复用当前筛选结果，不透明度变化保留在飞弹幕并立即更新。异常回溯的正则限时，超时规则在当前规则实例中停止重复重试；其他关键词继续工作。
3. 延迟回收执行时再次检查播放器登记：还有播放器存活时使用温和回收，避免对其执行 LOH 压缩和工作集回收。
4. 直播控制栏在淡入/淡出被打断时从当前透明度衔接。
5. 上一轮的单合成时钟、连续速度、统一播放表面、缓冲生命周期、最新帧上传、密集派发预算及隐藏时钟清理一起纳入本版。

新增后台筛选 9 项验证了 60,000 条时间轴的规则替换、旧结果隔离、外观调节及异常正则；多播放器 4 项验证了同时播放、关闭一个窗口后另一窗口继续推进及最终注销。

# BiliTouch 0.3.3

本版修复了离线缓存播放误走在线视频流的问题，并新增原生专栏／Opus 阅读页、评论装扮表情面板与原生态星创组同人站支持，同时继续完善网页布局评论虚拟化、下拉刷新跟手与转场动效流畅度。

- **离线缓存本地播放修复**：修复从「离线缓存」播放已缓存视频时，因 `PlayOfflineEntry` 携带 `bvid` 且播放器 `OnLoaded` 未区分本地播放状态而误触发 `LoadVideoAsync` 拉取在线流的问题；同步修正本地回放的重试与 `PlayVideo` 判重逻辑，确保缓存视频与官方客户端缓存始终走本地路径播放。
- **原生专栏／Opus 阅读与全文扩展**：新增原生专栏与 Opus 图文阅读页（支持经典专栏 HTML 与 Opus 模块排版解析），接入搜索「专栏」页签、UP 主个人空间专栏列表，以及动态、私信和链接跳转的原生打开。
- **原生态星创组浏览页**：新增 `StarPartyPage`，原生解析并展示星创组作品卡片、详情图文、截图画廊与原声曲包。
- **评论表情面板与虚拟化渲染修复**：新增 `EmotePickerPanel` 支持普通表情、已解锁收藏集／装扮表情与颜文字选择，完善评论发布回显与人机验证提示；修正网页布局缩放后 `VirtualizingCommentPanel` 视口坐标计算偏差导致的上方可见评论消失问题。
- **触控与转场交互优化**：优化下拉刷新在触屏早期接管与触控板弹性回弹的表现；修复播放器「弹幕设置」弹层内开关「弹幕描边」时的触控／鼠标事件穿透；在一镜到底进场动画期间缓存主卡片并延后右栏重绑定，减少首帧掉帧。

安装器包含程序及播放依赖；下载附件仅上传一个 setup.exe，源码随 `v0.3.3` 标签提供。

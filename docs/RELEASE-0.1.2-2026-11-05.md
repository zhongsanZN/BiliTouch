# BiliTouch 0.1.2（2026-11-05）

本包包含 0.1.1 快照之后所有源码修改，以及本轮调整。0.1.1 的既有文件保持不变。

## 本轮变化

- 视频评论详情顶部移除文字返回按钮，右下角在写评论按钮左侧增加同款 46×46 DIP 返回按钮。返回仅在评论详情中出现；返回后恢复原列表位置，展开的输入区位于两个按钮上方。
- 首页删除屏蔽入口及弹层，完整屏蔽管理迁到设置 → 通用，保留原规则与关键词持久化机制、卡片右键屏蔽、单项撤销和清除。
- 关于页中三作者卡可打开应用内个人主页，UID 349921038 已通过公开接口核对名称为“中三”；与鸣谢里的 ABing（697238372）保持独立。
- 简介改为“围绕触摸屏、触控板手势与人体工学持续打磨的哔哩哔哩第三方客户端”。
- 使用用户提供的插画制作粉色底图标，覆盖侧栏、程序/窗口/托盘以及安装器图标。原 BiliTouch 图标单独保存在 `Assets/upstream-original.png`，只由关于页鸣谢引用。
- 新图标通过内置 imagegen 编辑，提示词与产物信息见 `ICON-EDIT-2026-11-05.json`；PNG 到 Windows ICO 的转换包含 16/24/32/48/64/128/256 七种尺寸。

## 同时包含的前轮修改

首页刷新与动态页位置一致；主题切换和私信位于左下侧栏；动态转发/点赞使用视频详情同款图标且移除复制链接按钮；动态详情首批多页评论、滚动续载和右栏底部紧凑输入区；播放器去掉右栏重复的稍后再看，并铺开 UP 信息行。

触控板张开/捏合对应全屏进退，不再改变画面倍率；触屏、触控板、键盘与按钮退出全屏均恢复原窗口状态及普通窗口位置尺寸，包含最大化状态。

## 验证和边界

- Release 构建及 win-x64 发布通过。
- UI 专项 41 项、BiliTouch 回归 19 项、动态回归 112 项、播放器静音样片及触摸事件链 73 项通过，共 245 项。播放器记录见 `artifacts/release-0.1.2-player.log`。
- 渲染检查覆盖评论返回按钮、输入框不遮挡、关于页两栏、设置中的屏蔽编辑与规则撤销。相关截图为 `artifacts/touch-tests/release-*.png`。
- 当前桌面包为框架依赖版，需要 .NET 10+ Windows Desktop Runtime；安装器会检测运行时。源码和 GPL-3.0 许可随发行提供。
- 未运行真实账号下的发布/点赞/评论操作；未进行真实触屏和触控板设备的长时间手工验收。

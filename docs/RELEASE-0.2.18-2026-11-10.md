# 0.2.18

本版集中修复横滑翻页、视频详情的手势范围和首页切页等待。

- 触控板在支持原始接触输入的 Windows 上按实际位移跟手，以松手时的净位移决定切页。短距离快速滑动不会借速度直接翻页，一次接触最多到原来的相邻页。
- 连续同向、反向和打断吸附时保留两页的位置与已成立的切页结果，减少跳页和画面突变。取消或输入读取失败会结束本次预览，并过滤重复的系统横向滚动尾包。
- 视频画面横滑独立调节进度；详情右栏切页只在自己的内容区响应。首页、我的、动态、设置、消息和搜索按各自内容区接入触控板输入。
- 首页提前拉取五个页签的首批数据，准备首屏卡片和封面；切回直播复用现有列表。后台准备限流，滑动期间暂停新的卡片布局和列表发布。
- 首页首批请求合并，空结果可缓存；各页错误和分页状态独立，避免后台请求晚返回影响当前页面。设置页保留已创建的控件并在空闲时继续准备。
- 修复视频卡片进出播放器时的共享画面交接及关闭流程；更新检查能区分 `fixN` 修补版并匹配对应安装器文件名。

触控板原始接触接口不可用时保留系统滚动兼容路径。具体表现仍受 Windows、设备与驱动影响；本版不承诺所有设备均无卡顿。

Windows 10 / 11 x64。发行附件提供安装包，对应完整源码见本版标签；便携包保留在本机构建归档。

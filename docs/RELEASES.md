# 版本归档索引

下载入口：https://github.com/zhongsanZN/BiliTouch/releases 。当前推荐版本为 **0.2.2**。

| 版本 | 归档状态 |
| --- | --- |
| 0.2.2 | 当前版本：setup、便携包、对应源码包、校验值和验证记录 |
| 0.2.1 | 触控板灵敏度分离、常驻页头与主题图标版本 |
| 0.2.0 | 实验性视频增强与消息分类版本，保留完整原始产物 |
| 0.1.8、0.1.9 | 历史修复版本：保留原安装包、便携包及对应源码快照 |
| 0.1.7 | 历史问题版本：原生播放器打包存在问题，标注为预发布归档；不推荐安装 |
| 0.1.4、0.1.5、0.1.6 | 保留原安装包、便携包及对应源码快照 |
| 0.1.0～0.1.3、0.1.2-touch、0.1.3-cursor | 本机早期构建，因源码对应关系未完全确认，仅归档到仓库所有者可见的 Release 草稿 |
| BiliDesk 1.5.4 touch.2～touch.9 | 更名前的本分支构建，同样保存为草稿，未冒充上游正式版本 |

历史二进制原样保存，没有用当前代码重新编译后假装旧包。0.1.4～0.1.9 标签由该版本原有源码压缩包导入，源码目录可能仍沿用当时的 BiliDesk 命名。更早草稿中的 GitHub 自动源码下载指向当前分支，不代表对应旧二进制；需补齐匹配源码后才能转为公开版本。

旧包中的更新地址和行为也按原样保留；0.2.0 开始应用内更新正式指向中三的独立仓库。维护说明见 [MODIFICATIONS.md](MODIFICATIONS.md)，许可见根目录 LICENSE 和 NOTICE。

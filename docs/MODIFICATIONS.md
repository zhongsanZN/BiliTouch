# 本分支改动说明

维护者：中三（zhongsanZN）；整理日期：2026-11-06。

本项目基于 ABing / ABING1111 的 BiliDesk，沿用原 GPL-3.0 许可，保留原作者及上游来源。它是独立维护的衍生项目，不是上游官方发行。仓库、问题反馈和更新均指向 https://github.com/zhongsanZN/BiliTouch 。上游地址仅作来源和鸣谢使用。

## 主要改动范围

- 0.3.1 增加实际解码显卡选择及设备状态，改用显卡颜色转换和共享纹理合成以减少高分辨率播放开销，最小化时停止视频上传，异步串行切换原生媒体，修复登录同步等待，并整合账号隔离、收藏目标冻结、分页重试、音质保存读取及未读角标修复。详见 RELEASE-0.3.1-2026-11-11.md。

- 0.2.18 修复连续横滑、原始触控板位移和单次接触相邻页限制，限定视频详情手势范围，提前准备首页五页首屏，并隔离各页请求状态；详见 RELEASE-0.2.18-2026-11-10.md。

- 独立命名 BiliTouch、程序集、数据目录和升级/安装包；兼容旧数据迁移。
- 触摸屏与触控板首页翻页、信息流滚动、播放器手势、窗口与控制栏交互。
- 点播与直播窗口、网页布局、评论与图片、分 P 与合集、收藏及音轨处理。
- 综合动态流、关注列表及未读、个人主页、收藏/历史/缓存与消息模块。
- 星引擎装扮原资源适配、统一页头与图标、字体与 DPI 布局。
- 0.2.3 补齐设置/消息多输入方式的模块导航，统一分 P 展开区，改正动态点赞 JSON 协议和取消动作，并避免弹幕时间轴截断及后段超时丢失。
- 0.2.2 统一首页式子菜单，改进评论图片查看与滚轮路由，修复过渡抓帧的左上角预览及动态 BV 引用，增加主题网站入口。
- 0.2.1 分离触控板与鼠标滚轮灵敏度、常驻页头、评论竖图内联和主题图标布局，并更新真实界面截图。
- 0.2.0 加入实验性视频增强、驱动状态确认、多显卡偏好、消息分类与分页，修复搜索页重叠。

具体实现及原始提交作者保留于 Git 历史，逐版记录位于 docs/RELEASE-*.md；0.2.0 的验证边界见 RELEASE-0.2.0-2026-11-06.md。

## 源码与构建

完整应用源码、工程、发布脚本和测试随仓库提供。依赖通过 NuGet 恢复；需要 .NET 10 Windows SDK，安装器需 Inno Setup。运行 `dotnet build BiliTouch/BiliTouch.csproj -c Release`；发布见根目录 `发布.ps1` 与 `Publish/installer.iss`。

编译缓存、账号登录态、测试缓存与本机笔记不属于源码交付。公开历史整理移除了误跟踪的 artifacts 生成目录，保留业务源码提交顺序与作者。

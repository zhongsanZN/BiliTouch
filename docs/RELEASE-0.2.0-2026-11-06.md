# BiliTouch 0.2.0

- 直播加入触控板双指滚动调节亮度/音量、捏合全屏、横滑侧栏，与触屏手势共用播放器状态。
- 设置 → 通用 → 实验性新增画质增强。开启后才显示点播及直播控制栏开关。自动请求 NVIDIA / Intel / 摩尔线程厂商超分，其他显卡用视频处理器缩放；提供可选 SDR 转 HDR。
- 枚举 DXGI 显卡，允许保存 Windows 应用显卡偏好。VLC 3 不能精确绑定任意 LUID：同类多卡仍由 Windows 决定，切换偏好需重启。按钮提示分别显示请求状态和驱动确认；不把识别显卡等同于增强生效。
- 本机 Intel Arc B390 已从原生日志确认 VSR ON。NVIDIA、AMD、摩尔线程及 HDR 未逐机验证，属于实验性功能。
- 点播小窗弹幕随实际画面宽度缩小；网页布局切换使用解码帧弹性过渡，结束时提交原生播放器尺寸。
- 信息流默认滚动距离减半；新 100% 等于旧 50%。
- 设置子菜单裁字、字体下拉框显示名称修复。
- 星引擎点赞、投币/多币、收藏、分区使用用户指定原始素材；分区入口移到首页刷新左侧。
- 消息新增回复与 @、收到的喜欢、新增粉丝，支持分页。真实账号四类接口及第二页只读验证成功，每页 30 条且第二页无重复。
- 主题仅从左往右渐透，保留金黄分隔线，删除上下渐透。
- 搜索页统一 112 DIP 页头；分类第二行；结果从页头下方开始；搜索历史展开时避免分类命中重叠，收回后彻底隐藏边框；搜索框使用无系统边框模板。

## 验证与边界

WPF 布局、原生视频、增强开关、触控板、消息、主题、小窗及弹幕恢复回归通过。桌面电脑工具自动审批因额度耗尽未执行，不能视为本次人工点击验收。截图位于 artifacts/touch-tests/release020-*.png。

发布使用外置 LibVLC 原生库；安装器提取后与源载荷逐文件核验，并直接运行提取后的程序及便携程序验证初始化和播放时钟。

## 技术依据

- [VideoLAN D3D11 输出选项](https://github.com/videolan/vlc/blob/3.0.x/modules/video_output/win32/direct3d11.c)
- [VideoLAN 厂商超分实现](https://github.com/videolan/vlc/blob/3.0.x/modules/video_output/win32/d3d11_scaler.cpp)

超分选项配置在 LibVLC 实例上，不作为无效的媒体级参数传入；切换时保留仍可能被播放器引用的原生内核，退出时统一释放。

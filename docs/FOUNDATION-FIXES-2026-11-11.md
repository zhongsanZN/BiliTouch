# 基础能力修复记录 · 2026-11-11

对应 [基础能力审查](FOUNDATION-REVIEW-2026-11-11.md) 的 F01—F08。修改已落在当前工作区，没有覆盖原有播放器、封面和未读角标相关修改。

| 问题 | 修复结果 |
| --- | --- |
| F01 收藏夹误删目标 | 清空、批量移出和单条移出均固定操作开始时的收藏夹与账号。忙碌时阻止界面和直接方法切换；账号变化停止后续批次。清空中途失败会重新读取实际剩余内容，不显示已全部清空。 |
| F02 私信与草稿串号 | 账号变化立即清空会话、正文、草稿、通知、游标和待加载会话。发送要求当前会话属于本次登录；晚到的发送结果只更新原会话，不追加到另一联系人正文，也不清除后来编辑的新草稿。 |
| F03 旧账号响应回填 | 引入登录生命周期快照，退出再登录同一账号也使旧快照失效。历史、收藏、私信、通知、主界面资料、设置页资料、个人主页及稍后再看都增加账号校验；旧操作也不能释放新操作的加载状态。 |
| F04 收藏夹响应混入 | 收藏夹读取固定 folderId、page、页面代次和账号。旧响应不得改变当前列表、错误、分页或加载标志。 |
| F05 失败消耗页码 | 历史和收藏均在成功接受响应后提交页码，失败后再次加载仍请求原失败页。 |
| F06 重试签名错误 | 签名前移除旧 w_rid；请求使用参数副本。换密钥、退避重试保持原请求所属账号，不能在切号后继续恢复旧请求。 |
| F07 音质偏好丢失 | 加载时恢复 PreferredAudioQuality，并将无效枚举值归一为 Auto。全部音质档位均有保存—读取验证。 |
| F08 测试未自动执行 | Windows 工作流实际运行基础检查和限流检查，保留结果并传播失败退出码。搜索建议请求也接入可取消的全局限速。 |

账号变更通知统一切回界面线程，弱事件订阅避免缓存页面被全局事件永久保留。底层 JSON 读取和表单写入在等待限速、预热、重试及返回结果时验证所属登录；这不能撤销服务端已经接收的请求，但能阻止尚未发出及后续批次的旧操作。

顺带补上 UserCard 导航服务为空时的保护。

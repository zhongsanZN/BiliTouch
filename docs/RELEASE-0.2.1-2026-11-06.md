# BiliTouch 0.2.1

- 触控板信息流滚动距离再减半，默认灵敏度 100%；触屏逻辑不变。普通鼠标滚轮与触控板滑块解除耦合，升级时保留原滚轮距离。
- 设置说明只解释当前功能，删除旧版百分比对比文案。
- 点赞提示移除快捷键字母。
- 放大点赞、投币和收藏的主题图标，扩大图标占位，避免与数量重叠。首页分区使用放大的原始拼图图标和无底按钮，菜单跟随右上角入口展开。
- 首页、动态、我的、设置共用主窗口常驻装扮背景；页面内容过渡不再使装扮条淡出或重新加载。
- 视频并排布局中，竖图按评论区域原位展开；横图保留原有查看方式。支持根据图像实际尺寸修正元数据判断。
- 视频画质增强移动到设置 → 播放，标题旁增加实验性标签。
- GitHub README 首页截图更新为本版应用实际渲染画面。

验证包含 0.2.1 定向交互、触控板、图像/字体/音轨、主题、页头及 0.2.0 功能回归。最终 setup 提取载荷与发布目录逐文件核验，并分别运行安装器载荷和便携版检查真实视频起播与播放时钟。未通过桌面电脑工具实施硬件触控板或触屏点击复测。

# BiliTouch 0.1.3 累计更新（2026-11-05）

按用户新要求将版本升至 0.1.3，同步更新关于页、程序集、安装器和发行文件名；生成安装包、桌面压缩包和匹配源码包。既有 0.1.2 发行文件保持不变。

## 本次页头调整

- “N 条新动态”放在顶栏“发布动态”左边，仍由用户点击后插入新内容，不打断正在看的列表。
- 删除右栏重复的“全部动态／某 UP 的动态”标题行；当前选择继续在左侧高亮，并保留无障碍名称。
- 直播看板与左侧联系人区域顶端对齐，动态流整体上移。新动态提示出现/消失不再改变列表纵向位置。
- 刷新、新动态和发布入口保留至少 44 DIP 的触控区域；首页和动态刷新仍在同一位置，首页标题行不因按钮增加高度。
- 顶栏标题计数可以省略显示，避免较窄窗口中与操作按钮叠在一起。

## 此次一起纳入安装包的累计修改

- 我的：个人主页、真实关注/粉丝统计、可进入的关系列表、圆形下拉刷新指示。
- 私信：官方账号名称与头像、分享卡片/图片、统一联系人视觉与触摸选中位置。
- 设置 → 通用：触控板信息流灵敏度、并排/网页视频布局、系统/HarmonyOS Sans/荆南波波黑字体选择。
- 高频精细滚动按显示帧合并；保留信息流虚拟化与普通鼠标滚轮步长。
- 网页视频布局：评论在视频下方，向上阅读时同一个播放器平滑停靠到右侧分享、下载下方，退出全屏后恢复阅读位置。
- 评论看图：并排布局将视频靠上、图片放在下方；网页布局直接替换所点缩略图原位展开，不增添第二份预览。
- 高级音质：兼容 FLAC 单对象，720P 自动音质也检查高级音轨，缓存按音质隔离，切换同步重播和听视频地址。
- 原生界面、弹幕、菜单和提示字体即时更新，图标及 emoji 安全字体保持各自用途；内嵌字体无需系统安装。
- 粉色常态／蓝色按下鼠标，含内嵌网页；保留文本、尺寸调整、视频隐藏指针等用途。

## 鼠标尺寸修订（版本号保持 0.1.3）

应用鼠标从 60×60 缩至 30×30，保留原有粉色常态和蓝色按下样式。原生窗口按指定尺寸加载，内嵌网页以相同尺寸显示原图。鼠标专项 7 项通过，覆盖两种原生鼠标实际像素尺寸、网页尺寸、按下恢复与文本/调整尺寸指针。

# 0.2.18-fix1

本版集中修复高分辨率视频播放下的评论区卡顿、关闭视频返回首页重排、触控板连续滑动与卡片封面复用。

- 评论区视口虚拟化：新增单列变高视口虚拟化面板 VirtualizingCommentPanel，仅渲染视口与缓冲范围内的评论与楼中楼，常驻视觉树节点减少 95% 以上，彻底解决 1080P/4K 高清播放时评论区严重掉帧卡死。
- 消除返回首页重排跳动：修复 CardWall 虚拟化测量失效判定与尺寸公式对齐，前台视口给予完整帧预算，关闭全屏详情页回到首页不再触发瀑布流分帧重排。
- 封面内存复用与软光栅降级：滑出屏幕的卡片再次滑入时直接复用内存已解码位图，消除重复冷解码与闪烁；软件渲染模式下自动将封面缩放降为 LowQuality，大幅降低无独显/软解环境的 CPU 负载。
- 触控板连续滚动体验：手指不离开触控板支持由横向无缝继续竖向滑动，且初始竖滑自动加锁防误触横向切页。
- 调整横向切页判定阈值：切页阈值由 1/2 优化为 3/8（37.5%），翻页更轻巧跟手。

Windows 10 / 11 x64。发行附件提供安装包，对应完整源码见本版标签；便携包保留在本机构建归档。

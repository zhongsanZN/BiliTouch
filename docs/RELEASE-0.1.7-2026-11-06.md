# BiliTouch 0.1.7 — 2026-11-06

对应本轮 16 项反馈，源码位于本仓库 `BiliTouch/`。

| 反馈 | 本次修改 |
| --- | --- |
| 1 个人主页图片 | 画图区域扩展到卡片边缘；文字单独保留 26 DIP 内边距，图片不再被整个卡片的 padding 缩进去。 |
| 2 主题条 | 动态、我的、设置、搜索补上同一个 SkinSurface。 |
| 3 左侧主题 | 暗色/亮色图案不透明度分别由 .09/.07 降为 .045/.035。 |
| 4 动态 | 删除三枚排序按钮，默认按最近更新。刷新按 50 人分页连续拉取关注直到结束，去重、防重复页；不再依赖滚动。未读轮询改为 45 秒，始终扫描全局动态流，再补读 portal 的服务器更新标志；首次发现内容不再自动写成已读。初次动态回溯限最近七天，之后按扫描水位增量检查，避免无限翻阅全部历史。单个 UP 被本机阅读后，以本机阅读基准为准。 |
| 5 音量悬停 | 离开喇叭后保留 350ms 跨越间隙；弹层内悬停继续保留，离开弹层也能关闭。两个窗口一致。 |
| 6 点播弹幕 | 将运动驱动改为 Render 优先级 DispatcherTimer；protobuf 获取为空时增加 XML 兼容路径。专项检查实际验证浮层中的文字持续向左运动。 |
| 7 合集 | 头部增加收起合集、订阅合集，订阅仅由用户点击发起。 |
| 8 音质 | 审查发现自动选流仍优先 Hi-Res、杜比、最高码率；未加入转码或主动降质。本次修复音频尾部缺失，但不能用代码审查代替听感验证。 |
| 9 直播 | 关注左侧补头像名字，视频覆盖层使用可命中的近透明背景并拉伸；使用已有 VideoBackdropInterop 修正原生宿主白底，移除底栏重复侧栏按钮；共用 PlayerTouchSession 左亮度右音量，增加手势反馈、双击/捏合全屏、捕获丢失和多指取消。直播横滑不进行点播式进度跳转。 |
| 10 装扮表情 | 动态表情缓存未命中时异步下载，并通过内容代次防止虚拟化复用后贴错图；评论表情解码随实际尺寸与 DPI 变化。未实现 GIF/WebP 动图逐帧播放。 |
| 11 上游 | 比对 v1.6.1...v1.6.3 的实际代码差异，移植媒体级 avformat 音频尾分片修复，以及播完后跳转先重建 Media 的处理。保留本分支触控、音质、关键词和布局逻辑。 |
| 12 评论 | 删除评论回复区域的冗余悬浮提示。 |
| 13 面板 | 清晰度、弹幕设置、倍速使用显式目标和 CustomPopupPlacementCallback，上方右缘对齐，避免混用独立 HWND 尺寸和 WPF 逻辑尺寸。 |
| 14 分 P | 将原分 P Popup 改为简介中的内联面板，放在合集前，自动显示多 P 列表；保留现有切 P 行为。 |
| 15 字体 | manifest 已是 PerMonitorV2；窗口启用像素对齐和布局取整，统一 Ideal/Auto 文本渲染，清除主页和播放器局部 Display 模式。自选字体本身的字形风格保留；尚未逐个显示器验收。 |
| 16 收藏 | 点击默认收藏夹；已收藏再次点击从当前所在收藏夹移除；按住 550ms 打开选择面板。默认收藏夹先认服务器标记/默认标题，旧响应回退最早创建的收藏夹。切片代次检查、防重复提交和成功后更新状态仍保留。 |

上游依据：[v1.6.3](https://github.com/ABING1111/BiliDesk/releases/tag/v1.6.3)。

## 验证

Release 编译成功。默认 56、专项 10、直播 45、播放布局 28、连续播放交互 25、动态 112、关注/未读 53、音频/图片/字体 34、主题 28，共 391 项通过。旧测试中“必须存在三枚排序按钮”“初次发现自动已读”的断言已按用户本次要求更新。

真实 WPF/LibVLC 窗口夹具已检查；画面截图位于 `artifacts/touch-tests/`，命令输出位于上级 `artifacts/recheck*.log`。个人主页宽屏截图已人工查看，背景抵达卡片边缘。已有 UserCard 空引用警告及部分驱动 SetThumbNailClip 日志仍存在，未把它们归为已解决。

没有对真实账号发送收藏、取消收藏、关注或订阅操作。真实账号关注总数、与其他客户端未读一致性、合集订阅写入、真实视频尾部音频与完整触屏体验尚需实机验收；391 项不代表上述内容均已实测。没有替换当前正在运行的旧程序。

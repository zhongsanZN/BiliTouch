# BiliTouch 0.1.9 实测修复记录（2026-11-06）

本轮使用电脑操作检查已安装在 Program Files 的 0.1.8，修复源码并生成 0.1.9 setup.exe。

## 实际复现与修复

- 点播弹幕：实际账户设置是总开关开启、滚动/固定/彩色/高级四种类型全关闭。生产过滤器因此丢弃全部弹幕，按钮却显示“关闭弹幕”。在设置界面恢复四种类型后，同一真实视频 BV1gB4t6NETg 出现滚动弹幕，跳转至约 02:23 后仍正常出现。此配置的形成原因不能仅凭文件判断。0.1.9 对无迁移标记、总开关开启但全部类型关闭的旧配置进行一次恢复；新版本用户明确选择全部隐藏时保留选择。类型区改为“显示的弹幕类型”，增加全隐藏说明和一键恢复；播放器也能识别全隐藏状态并提供恢复。新增加载数量诊断，避免接口失败与过滤为空无法分辨。
- 托盘：真实 errors.txt 记录图标资源缺失。版本化 ICO 作为发布文件存在，但资源键读取失败。优先读取随包 ICO；只有托盘确实可用才关闭到托盘，托盘不可用时“最小化到托盘”退为普通最小化。
- 设置页：滚动条与窗口右侧缩放边框接近，增加右侧留白。
- 关注直播条：实际点中间空白没有反应，点文字才展开。改成完整按钮，支持整行点击和键盘操作；收起/展开箭头方向与操作一致。
- 直播：真实播放、实时弹幕、主播头像名字已确认。初始焦点会落到聊天框，原生视频覆盖窗口未转接快捷键。补齐点播已有的覆盖层键盘转接、画面焦点、关闭清理；加载、起播和尺寸变化期间复用原生黑底短时守护。

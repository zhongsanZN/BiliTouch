# BiliTouch 0.3.2

本版围绕动效连续性、全站交互统一、弹幕描边、Windows 官方客户端离线缓存识别，以及设置与播放器触控交互修复进行了集中更新。

- **弹幕描边与弹幕设置弹层修复**：新增轻量可控的弹幕描边渲染选项并集成至点播与直播弹幕设置，默认关闭；重写点播「弹幕设置」弹层为非模态收放与统一拨片样式，修复点击「开启」后鼠标事件被抢占导致界面卡死或状态未生效的问题。
- **哔哩哔哩 Windows 客户端离线缓存识别与合集二级视图**：自动扫描并识别官方 Windows 客户端默认缓存路径下的已完成离线缓存，兼容混淆头 m4s 视频/音轨无损解封装播放并完整展示封面与时长；支持按 `groupId` 将多分 P 与跨 BVID 系列合集折叠为双列网格卡片，点击进入二级分集页，不破坏官方客户端源文件。
- **并排 / 网页一镜到底动效与切换过渡清晰化**：优化播放器开合的连续视口交接并减少关闭重排闪烁；为消息页、搜索页等补齐实时 WPF 控件横滑预览与高 DPI 感知，淘汰模糊截屏过渡；消息页分栏缓存保留已加载条目，避免切换子菜单反复转圈拉取。
- **全站统一化与跟手体验优化**：提高下拉刷新触发阈值至 `120` DIP，为全部启用下拉刷新的页面统一接入随动阻尼位移与回弹动画；提炼通用 `FeedStatusOverlay`、`SwitchToTab`、Fluent `LabeledCheckBoxStyle`/`SettingsToggleStyle` 等共享组件与交互逻辑；按评论区 `TrimRepliesToPreview` 预览回收、封面分辨率阶梯量化与 `MemoryTrim` 等方式优化内存开销；完善检查更新 `test` 与正式版本比较规则。
- **布局切换与并排右栏触控修复**：修复设置页因横向预览副本共用 `GroupName` 导致选择「并排布局」后无法切回「网页布局」的双向绑定覆盖问题；修复播放器并排布局右栏触控横滑时因子控件 `LostTouchCapture` 冒泡误清状态导致的「简介 ↔ 评论」切页失效。

安装器包含程序及播放依赖；下载附件仅上传一个 setup.exe，源码随 `v0.3.2` 标签提供。

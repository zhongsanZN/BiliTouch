# 0.2.5 互动、滚动与装扮修订

## 最终行为

- 影之刃零主题的“主题互动效果”默认开启，说明同步提示低音量升级音效。成功新增点赞播放用户指定的“武器升级-成功”，保留原时长、48 kHz 双声道 PCM16，仅降至 18% 振幅（实测 RMS 比 0.180001，约 -14.9 dB）。取消和失败不播放，关闭效果或换主题即停止，与视频音轨和音量独立。
- 点赞、投币、收藏在现有道具上产生铜色、翠色、蓝色短暂光效，不再叠画或弹出第二份素材；默认和星引擎反馈保留。光效结束、关闭效果、卸载控件时释放动画。
- 查看带红点的 UP 后，服务端确认会更新红点和汇总，但左栏顺序与选中行保留，后续轮询、补页及全部已读也不会把当前浏览对象移走。手动刷新页面后才恢复未读优先的分组；刷新重新绑定当前 UP 对象，保留选中态。
- 视频详情并排评论栏接入平滑滚动，网页评论区缩短缓动至 160 ms。快速连续滚轮保留尚未消耗的距离，反向从当前位置立即接管；触控板继续按帧合并输入，点击或触摸能停止旧缓动。
- 个性装扮实际下拉框有默认、星引擎和影之刃零三个选项。路径为“设置 → 通用 → 外观 → 个性装扮”。本地成品统一标为 0.2.5，旧进程应完全退出后再打开新版本，避免单实例把新启动请求转交给旧进程。

## 按用户后续反馈修订的材质与尺寸

顶部与侧栏改用用户官网包的 `preorder-platform-bg.png` 织物细纹及 `preorder-edition-bg-deluxe.png` 金箔材质。原织物的低 alpha 在显示阶段单独处理，暗色模式保留纤维细节。水墨宣纸放在首页视频卡片下方及视频详情内容区，不新增卡片矩形底板。资源是官网原材质，未生成或重绘。

横向与纵向边界使用愿望单的 `wishlist-divider.png` 细刀痕，侧栏旋转使用；依主题调节线条颜色，保留透明轮廓。额外的侧栏外框曾占用 1 DIP，而主题自身已经绘制分隔，这导致两块材质之间露出细缝；现去除外框占位并启用像素对齐，保留原分栏及横、竖分隔结构。

播放圆环按可见轮廓和按钮实际大小适配，40px 按钮使用 38px 图标。绘制和测量采用方形素材范围，避免原三角几何的 11:14 比例把圆环压窄。暂停和卡片播放量小图标保留原尺寸，主播放器、小窗和直播使用同一组件。

## 关联会话成果

原性能会话结尾的控制栏过渡隐藏、官方未读快照与确认、旧排序配置迁移、有效音轨恢复与延迟回调代次校验继续保留。没有重新合并另一份重复实现；详见 0.2.4 的交付记录及原审计文档。

## 验证记录

定向 WPF 回归日志在 `artifacts/touch-tests/release-0.2.5-*.log`。主题接缝覆盖默认、星引擎、影之刃零，100%／125%／150% 缩放及明暗两种模式，测量实际装扮绘制右边缘与顶部条左边缘，不保留额外边框间隔。

评论检查使用产品真实长评论控件，验证中间偏移、连续滚轮距离、反向接管、精密输入合并及点击停止。光效检查操作真实播放器控件，确认没有重复精灵，关闭开关后不回退到道具弹出。播放图标另在真实加载的按钮视口检查实际尺寸与渲染，避免 VideoView 未挂载原生覆盖窗时误测。

直播旧夹具只调用了预览滚轮回调，没有实际移动视口，可能被下一次布局正确地恢复为“已在底部”。现改为真实预览和冒泡滚轮输入，先确认已向上滚动，再验证新弹幕不抢回底部；没有修改产品直播跟随逻辑。

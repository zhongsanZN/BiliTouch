# 0.2.10 退出全屏后视频变黑的修复与验证补强（2026-11-08）

## 最终改动

- 修复网页布局下退出播放器全屏后**视频区永久变黑**（0.2.9 闪退修好之后暴露的第二个问题）。
- 挂载网页布局时在动任何子元素之前钉住 `VideoSurface` 的实际尺寸，避免宽度／高度经过 0×0。
- 卸载网页布局时把"切回 Stretch"放在"清成 NaN"之前，同一目的。
- `--verify-fullscreen` 探针改为**看屏幕**判定画面是否存在，不再只依赖播放器时间。
- 回归新增一条断言：进出全屏全程视频区不得出现 0 尺寸。
- 应用、程序集、安装器、发布脚本同步为 0.2.10。

## 黑屏的根因

现象：网页布局下退出播放器全屏，进程不崩、音频继续、进度条继续走，但视频区永久变黑。

链路（探针 + libvlc 日志双向确认）：

1. 挂／卸网页布局会改 `VideoSurface` 的 `HorizontalAlignment` / `VerticalAlignment`。
2. 原生布局下它的 `Width` / `Height` 是 `NaN` —— `Stretch + NaN` 表示"按父级拉伸"，尺寸正常。
3. `Left/Top + NaN` 则表示"按内容量尺寸"；内容是 `VideoView`（HwndHost），没有期望尺寸 ⇒ **量成 0×0**。
4. 0×0 立刻下发 `SetWindowPos`。libvlc 侧日志：
   ```
   VoutDisplayEvent 'resize' 0x0
   destroying useless vout
   Win32VoutCloseWindow
   ```
   d3d11 把 pool 和 vout 一起销毁，**之后不再重建** —— 所以后面把尺寸改回正确值也没用。

实测尺寸时间线（`VideoSurface.SizeChanged`，进出全屏各一次）：

```
752x423.1  →  1386.7x924.4        ← 进全屏
1386.7x924.4  →  0x0              ← 这一步销毁 vout
0x0  →  962.7x541.3  →  752x423.1 ← 尺寸回来了，但 vout 不会
```

修复后同一条路径：

```
752x423.1  →  1386.7x924.4
1386.7x924.4  →  962.7x541.3  →  752x423.1
```

`0×0` 消失，画面全程在。20 轮进出全屏全部通过，亮度维持在基线的 110% 左右。

## 为什么 0.2.9 的探针没发现

0.2.9 的 `--verify-fullscreen` 每轮只检查 `player.Time` 是否推进。而黑屏时：

- 解码器正常出帧（音频、时间都对）；
- `player.TakeSnapshot()` 也照样有图（它取的是解码器吐的帧，不是屏幕）。

⇒ 两条判据都"通过"，但屏幕上什么都没有。**唯一能区分的是屏幕本身。**

## 本版探针的判据

`--verify-fullscreen` 现在：

- 进全屏**之前**先按 `VideoSurface` 的屏幕矩形取样，得到基线亮度；基线过暗（< 4）直接报错，
  避免拿一段全黑视频当"通过"。
- 每轮退出全屏后重新取样；亮度 / 基线 < 0.35 判为黑屏并中止，失败信息里带具体数值。
- 每轮存一张 PNG（`fullscreen-roundN.png`）供人眼复核。
- 记录 `VideoSurface` 与 `VideoView` 的**每一次**尺寸变化，出现 0 宽／0 高就记进结果文件。
- 支持 `--no-enhancement`（切 linear，绕开 d3d11 缩放）、`--enhancement-mode=`
  （processor / super 分别验）、`--no-weblayout`（关网页布局）用于隔离对照。

取样走 GDI `BitBlt`，不引第三方库，也不碰 `System.Drawing`（本工程 csproj 里移除了它）。

## 隔离对照（证明黑屏确实由网页布局引起）

同一段视频、同一台机器、同样进出全屏：

| 配置 | 结果 |
| --- | --- |
| 网页布局 + super 缩放 | **黑屏**（亮度 0.1 / 基线 116.4） |
| 网页布局 + processor 缩放 | **黑屏**（亮度 0.1 / 基线 116.4） |
| 网页布局 + linear（关增强） | 正常，亮度 126.9 |
| **关网页布局** + super 缩放 | 正常 |

⇒ 黑屏与"d3d11 缩放模式"无关，与**网页布局的挂／卸**绑定，与用户"只有网页布局会这样"的观察一致。

## 回归

- 12 个套件、**441 项检查全绿**。
- `web-player-layout` 新增断言：进出全屏全程 `VideoSurface` 不得出现 0 尺寸。
  反向验证：把 `PinVideoSurfaceSize()` 去掉后这条断言立刻失败，报出
  `1386.7x924.4→0x0, 1386.7x924.4→0x0` —— 说明它真的能抓住这个 bug，不是摆设。
- `--verify-fullscreen --rounds=20` 在 10 分钟素材上 20 轮全过，`0x0` 出现 0 次。

# 影之刃零互动音效包

`like.wav` 来源于用户指定的本地提取文件“武器升级-成功.wav”，Wwise 事件为 `SFX_UI_Int_LevelUp_Weapon_Success`。保持全长、48 kHz 双声道 PCM16，以 0.18 倍振幅（约 -14.9 dB）降低声音，未裁剪、混音或另加合成音。研究资料保留原始 WAV。

影之刃零主题下，成功新增点赞时异步播放，取消点赞和失败不播放。共用默认开启的“主题互动效果”开关；关闭效果、切换主题、退出应用会停止声音。与视频播放器音量及音轨独立，诊断静音参数同样会禁止主题声音。
